# 添加板卡与工程总览

本文只解决两件事：**看清工程长什么样**、**把一块新板卡接进来**。
其余细节一律指向 `learning/` 与 `配置分析/`，本文不重复。

---

## 一、工程总览

### 1.1 技术栈

| 项 | 值 |
| --- | --- |
| 平台 / 板卡 | ESP32（`board = esp32dev`） |
| 框架 | Arduino |
| 平台版本 | `espressif32@3.0.0`（`platformio.ini` 注释：temporary fix for lost uart rx characters） |
| 构建工具 | PlatformIO，`default_envs = release` |
| 主频 / 串口 | 240 MHz / 115200（`monitor_speed`，`monitor_eol = CRLF`） |
| 分区表 | `min_spiffs.csv` |
| 当前默认板卡 | `Machines/Wainlux_K11_HIM.h`（由 `Machine.h` 第 11 行决定） |

`platformio.ini` 逐项解释、构建流程、上传与监视命令见 [`../learning/01_工程结构与构建系统.md`](../learning/01_工程结构与构建系统.md)。

### 1.2 目录骨架

```
Grbl_Esp32/
├── platformio.ini          构建配置（src_dir = Grbl_Esp32）
├── Grbl_Esp32.ino          Arduino 入口
├── Grbl_Esp32/src/         固件源码（下文路径均相对此目录）
│   ├── Machine.h           ★ 板卡选择器
│   ├── Config.h            编译期全局配置（轴数上限、任务核心、特性开关）
│   ├── Machines/*.h        ★ 板卡定义，现有 28 个
│   ├── Custom/             板卡专属 .cpp（弱函数实现放这里）
│   ├── Motors/ Spindles/   电机 / 主轴驱动体系
│   ├── WebUI/              内置 Web 控制台
│   └── GCode / Planner / Stepper / Limits ...  运动控制核心
├── libraries/              随仓库分发的第三方库（非 PIO 下载）
└── doc/                    文档与本机实测记录
```

模块逐文件说明见 [`../learning/01_工程结构与构建系统.md`](../learning/01_工程结构与构建系统.md)。

### 1.3 分层（一句话版）

应用层（WebUI / SD / UserOutput）→ 通信层（Serial / WebServer）→ 系统层（Protocol / Settings / System）→ 运动层（GCode → Planner → Stepper / Limits）→ 硬件抽象层（Machines / Motors / Spindles）。

**添加板卡只动最底层的 `Machines/`（必要时加 `Custom/` 里的实现），上面四层不用改。**

完整分层图、5 种设计模式、双核分工与中断优先级见 [`../learning/02_架构设计与分层.md`](../learning/02_架构设计与分层.md)。

## 二、添加新板卡

### 2.1 六步

1. 复制一个最接近的现成板卡到 `Grbl_Esp32/src/Machines/MyBoard.h`
2. 改 `MACHINE_NAME`（出现在启动横幅与 `$$` 报告）
3. 需要非 3 轴时改 `N_AXIS`（不写默认 3，上限 `MAX_N_AXIS = 6`）
4. 改引脚：`*_STEP_PIN` / `*_DIRECTION_PIN` / `*_LIMIT_PIN`
5. 选 `SPINDLE_TYPE` 与辅助功能引脚
6. 让编译选到它（见 2.3），烧录后逐项验证

选参考模板：

| 需求 | 参考文件（`src/Machines/`） |
| --- | --- |
| 3 轴 + PWM 主轴，最简 | `3axis_v4.h` |
| 4 / 6 轴 | `4axis_external_driver.h`、`6_pack_stepstick_v1.h` |
| Trinamic SPI / StallGuard | `6_pack_trinamic_stallguard.h`、`TMC2209_4x.h` |
| 双电机同轴（Ganged） | `mpcnc_v1p2.h` |
| RC 伺服 Z 轴 | `pen_laser.h` |
| 无硬件，只验证编译 | `test_drive.h` |
| 并联臂 / 极坐标 / CoreXY | `parallel_delta`（`Custom/`）、`polar_coaster`（`Custom/`）、`CoreXY.cpp`（`Custom/`） |

配置项全量字典与「创建新配置最佳实践」见 [`../配置分析/机器配置完全指南.md`](../配置分析/机器配置完全指南.md)；四个典型板卡的逐行解读见 [`../learning/13_典型机器配置解析.md`](../learning/13_典型机器配置解析.md)。

### 2.2 最小可用模板

```cpp
#pragma once
// clang-format off        // 板卡文件必须关闭格式化，否则引脚宏会被重排

#define MACHINE_NAME            "MyBoard"
#define N_AXIS                  3

#define X_STEP_PIN              GPIO_NUM_26
#define X_DIRECTION_PIN         GPIO_NUM_16
#define X_LIMIT_PIN             GPIO_NUM_36
#define Y_STEP_PIN              GPIO_NUM_25
#define Y_DIRECTION_PIN         GPIO_NUM_27
#define Y_LIMIT_PIN             GPIO_NUM_39
#define Z_STEP_PIN              GPIO_NUM_14
#define Z_DIRECTION_PIN         GPIO_NUM_12
#define Z_LIMIT_PIN             GPIO_NUM_35

#define STEPPERS_DISABLE_PIN    GPIO_NUM_13

#define SPINDLE_TYPE            SpindleType::PWM
#define SPINDLE_OUTPUT_PIN      GPIO_NUM_2
#define SPINDLE_ENABLE_PIN      GPIO_NUM_22

#define COOLANT_MIST_PIN        GPIO_NUM_21
#define COOLANT_FLOOD_PIN       GPIO_NUM_23
#define PROBE_PIN               GPIO_NUM_32

// clang-format on
```

除 `MACHINE_NAME` 与各轴 `*_STEP_PIN` 外，其余全部可省略；省略即该功能不启用。
模板里的 GPIO 2 / 12 属于启动相关引脚，做输出可用（原因见 2.4）；限位放在 GPIO 34–39 这类输入专用引脚上，**没有内部上拉**，硬件必须补上拉电阻。

### 2.3 让编译选到板卡

**方式一：改 `Machine.h`**（Arduino IDE 下只能用这种）

```cpp
// Grbl_Esp32/src/Machine.h 第 11 行
#    include "Machines/Wainlux_K11_HIM.h"   // ← 换成你的板卡
```

**方式二：编译时指定**（推荐，不改源码，可多板卡并行构建）

```ini
; platformio.ini 的 [common] 段
build_flags = -DMACHINE_FILENAME=MyBoard.h
```

⚠️ **`MACHINE_FILENAME` 不能带 `Machines/` 前缀** —— `Machine.h` 会自己拼成 `<src/Machines/…>`，写了前缀就变成 `src/Machines/Machines/…` 直接编译失败。

### 2.4 红线与易错点

| 事项 | 要求 |
| --- | --- |
| 启动引脚 | GPIO 0 / 2 / 5 / 12 / 15 **可以用**，限制在「外部电路不能把上电电平拉偏」：GPIO0 被下拉进下载模式、GPIO2 被上拉无法从 Flash 启动、GPIO5 必须为高、GPIO12 被上拉会改变 Flash 工作电压、GPIO15 被拉低会静音启动日志。现成板卡里 24/28 个在用 GPIO 12，2 个在用 GPIO 5 |
| 串口引脚 | GPIO 1 / 3 是 UART0，占用了就烧不了程序也看不到日志 |
| 输入专用 | GPIO 34–39 只能做输入、无内部上拉，做限位/急停必须外接上拉 |
| Flash 引脚 | GPIO 6–11 接 SPI Flash，绝不可用 |
| 不存在的引脚 | GPIO 20 / 24 / 28 / 29 / 30 / 31 / 37 / 38 |
| 推荐引脚 | 4、13、14、16–19、21–23、25–27、32、33 |
| 格式化 | 板卡文件首行 `// clang-format off` |
| 轴数 | `N_AXIS` ≤ 6（`Config.h` 的 `MAX_N_AXIS`），改轴数要补齐该轴全部引脚 |
| 核心代码 | 不为适配板卡去改 `GCode.cpp` / `Planner.cpp` / `Stepper.cpp`，实时性约束见 [`../learning/02_架构设计与分层.md`](../learning/02_架构设计与分层.md) §技术约束 |
| WiFi + 蓝牙 | 共享射频，不能同时全功率使用；共存崩溃面见 [`../崩溃分析/0_ESP32崩溃分析方法论.md`](../崩溃分析/0_ESP32崩溃分析方法论.md) §5.3.1 |
| 引脚硬编码 | 引脚只写在 `Machines/*.h`，不写进核心代码 |

引脚冲突、启动引脚症状、Trinamic 通信失败等具体排查见 [`../learning/13_典型机器配置解析.md`](../learning/13_典型机器配置解析.md) §常见配置问题；逐个 GPIO 的启动限制说明见 `Machines/Wainlux_K11_HIM.h` 开头的引脚注释块。

### 2.5 板卡专属逻辑：弱函数

引脚解决不了的事（上电初始化外设、换刀动作、运动学）用弱函数覆盖，**不改核心代码**。实现在 `Grbl_Esp32/Custom/*.cpp` 或板卡同名 `.cpp`。

| 弱函数 | 时机 | 定义处 |
| --- | --- | --- |
| `machine_init()` | 初始化末尾、主循环前 | `Grbl.cpp` |
| `display_init()` | 显示器初始化 | `Grbl.cpp` |
| `machine_after_init_message()` | 启动完成打印 | `Report.cpp` |
| `user_m30()` | 程序结束 M30 | `Grbl.cpp` |
| `user_tool_change(uint8_t)` | 换刀 | `Grbl.cpp` |
| `user_defined_homing(uint8_t)` | 自定义归零 | `Limits.cpp` |
| `limitsCheckTravel(float*)` | 软限位越界检查 | `Limits.cpp` |
| `user_defined_macro(uint8_t)` | 面板宏按钮 | `System.cpp` |
| `custom_safety_door_check()` | 安全门逻辑 | `System.cpp` |
| `cartesian_to_motors()` / `motors_to_cartesian()` | 逆/正运动学 | `MotionControl.cpp` |
| `kinematics_pre_homing()` / `kinematics_post_homing()` | 归零前后 | `MotionControl.cpp` |
| `forward_kinematics(float*)` | 正向运动学刷新 | `MotionControl.cpp` |

签名、示例、调用时机与内存/阻塞限制见 [`../learning/12_弱函数与扩展机制.md`](../learning/12_弱函数与扩展机制.md)。
