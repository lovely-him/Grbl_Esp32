# 弱函数与扩展机制

## 弱函数概述

弱函数（Weak Function）是Grbl_Esp32提供的主要扩展机制，允许在不修改核心代码的情况下自定义行为。

### 弱函数定义

```cpp
// Grbl.h
void __attribute__((weak)) machine_init();
void __attribute__((weak)) display_init();
void __attribute__((weak)) user_m30();
void __attribute__((weak)) user_tool_change(uint8_t new_tool);
bool __attribute__((weak)) user_defined_homing(uint8_t cycle_mask);
void __attribute__((weak)) user_defined_macro(uint8_t index);
```

**工作原理**：
- 核心代码提供弱定义（默认为空）
- 机器配置文件可提供强定义（覆盖默认）
- 编译时链接器选择强定义

## machine_init - 机器初始化

**调用时机**：在 `grbl_init()` 中，所有硬件初始化完成后

**用途**：初始化自定义硬件、配置额外GPIO

### 默认实现

```cpp
// Grbl.cpp
void __attribute__((weak)) machine_init() {
    // 默认为空
}
```

### 自定义示例

```cpp
// Machines/my_machine.h
void machine_init() {
    // 1. 初始化自定义LED
    pinMode(STATUS_LED_PIN, OUTPUT);
    digitalWrite(STATUS_LED_PIN, HIGH);

    // 2. 初始化I2C设备
    Wire.begin(SDA_PIN, SCL_PIN);
    Wire.setClock(400000);  // 400kHz

    // 3. 初始化外部ADC
    pinMode(ADC_CS_PIN, OUTPUT);
    digitalWrite(ADC_CS_PIN, HIGH);

    // 4. 初始化风扇控制
    pinMode(FAN_PIN, OUTPUT);
    ledcSetup(FAN_PWM_CHANNEL, 25000, 8);
    ledcAttachPin(FAN_PIN, FAN_PWM_CHANNEL);

    // 5. 打印自定义信息
    grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info,
                   "Custom hardware initialized");
}
```

### 常见用途

**1. 初始化显示器**

```cpp
void machine_init() {
    // OLED显示器
    display.init();
    display.flipScreenVertically();
    display.setFont(ArialMT_Plain_10);

    // 显示启动画面
    display.clear();
    display.drawString(0, 0, "Grbl_ESP32");
    display.drawString(0, 16, MACHINE_NAME);
    display.display();

    // 创建显示更新任务
    xTaskCreate(displayUpdateTask, "display", 4096, NULL, 1, NULL);
}
```

**2. 初始化外部I/O扩展器**

```cpp
void machine_init() {
    // MCP23017 I/O扩展器
    Wire.begin();

    // 配置为输出
    Wire.beginTransmission(MCP23017_ADDR);
    Wire.write(0x00);  // IODIRA寄存器
    Wire.write(0x00);  // 全部输出
    Wire.endTransmission();

    // 初始状态
    Wire.beginTransmission(MCP23017_ADDR);
    Wire.write(0x12);  // GPIOA寄存器
    Wire.write(0x00);  // 全部低电平
    Wire.endTransmission();
}
```

**3. 初始化温度传感器**

```cpp
void machine_init() {
    // DS18B20温度传感器
    oneWire.begin(TEMP_SENSOR_PIN);
    sensors.begin();

    // 创建温度监控任务
    xTaskCreate(tempMonitorTask, "temp", 2048, NULL, 1, NULL);
}

void tempMonitorTask(void* param) {
    while (true) {
        sensors.requestTemperatures();
        float temp = sensors.getTempCByIndex(0);

        if (temp > 80.0) {
            // 温度过高，触发报警
            sys_rt_exec_alarm = ExecAlarm::AbortCycle;
            grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Warning,
                          "Temperature too high: %.1f C", temp);
        }

        vTaskDelay(pdMS_TO_TICKS(5000));  // 5秒检查一次
    }
}
```

## display_init - 显示器初始化

**调用时机**：在 `grbl_init()` 早期，串口初始化后

**用途**：初始化LCD/OLED显示器

### 自定义示例

```cpp
// Machines/my_machine.h
#include <SSD1306Wire.h>

SSD1306Wire display(0x3c, SDA_PIN, SCL_PIN);

void display_init() {
    display.init();
    display.flipScreenVertically();
    display.setFont(ArialMT_Plain_10);

    // 显示启动信息
    display.clear();
    display.drawString(0, 0, "Grbl_ESP32");
    display.drawString(0, 16, GRBL_VERSION);
    display.drawString(0, 32, MACHINE_NAME);
    display.display();

    delay(2000);  // 显示2秒
}
```

### 显示更新任务

```cpp
void displayUpdateTask(void* param) {
    while (true) {
        display.clear();

        // 第1行：状态
        display.drawString(0, 0, state_name[sys.state]);

        // 第2行：位置
        char buf[32];
        float x = sys_position[X_AXIS] / axis_settings->steps_per_mm[X_AXIS];
        float y = sys_position[Y_AXIS] / axis_settings->steps_per_mm[Y_AXIS];
        float z = sys_position[Z_AXIS] / axis_settings->steps_per_mm[Z_AXIS];
        snprintf(buf, sizeof(buf), "X%.2f Y%.2f Z%.2f", x, y, z);
        display.drawString(0, 16, buf);

        // 第3行：进给速率
        snprintf(buf, sizeof(buf), "F:%d S:%d",
                st_get_realtime_rate(),
                spindle->get_current_rpm());
        display.drawString(0, 32, buf);

        // 第4行：覆盖值
        snprintf(buf, sizeof(buf), "Ovr F:%d%% R:%d%% S:%d%%",
                sys.f_override,
                sys.r_override,
                sys.spindle_speed_ovr);
        display.drawString(0, 48, buf);

        display.display();

        vTaskDelay(pdMS_TO_TICKS(100));  // 100ms更新一次
    }
}
```

## user_m30 - 程序结束回调

**调用时机**：执行M30命令时

**用途**：自定义程序结束行为

### 自定义示例

```cpp
void user_m30() {
    // 1. 关闭外部设备
    digitalWrite(VACUUM_PIN, LOW);
    digitalWrite(DUST_COLLECTOR_PIN, LOW);

    // 2. 发送通知
#ifdef ENABLE_NOTIFICATIONS
    WebUI::notificationsservice.sendMSG("Job completed!");
#endif

    // 3. 播放蜂鸣器
    tone(BUZZER_PIN, 1000, 500);  // 1kHz, 500ms

    // 4. 记录日志
    grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info,
                   "Job completed at %s", get_timestamp());

    // 5. 更新显示
    display.clear();
    display.drawString(0, 0, "Job Completed!");
    display.display();
}
```

## user_tool_change - 换刀回调

**调用时机**：执行M6命令时

**用途**：自动换刀序列、刀具长度补偿

### 自定义示例

```cpp
void user_tool_change(uint8_t new_tool) {
    grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info,
                   "Tool change to T%d", new_tool);

    // 1. 移动到换刀位置
    float tool_change_pos[MAX_N_AXIS] = {
        TOOL_CHANGE_X,
        TOOL_CHANGE_Y,
        TOOL_CHANGE_Z,
    };

    plan_line_data_t plan_data;
    plan_data.feed_rate = 1000;
    mc_line(tool_change_pos, &plan_data, sys_position);
    protocol_buffer_synchronize();

    // 2. 停止主轴
    spindle->stop();

    // 3. 等待用户换刀
    sys.state = State::Hold;
    grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info,
                   "Please change tool and press cycle start");

    // 等待循环启动
    while (sys_rt_exec_state.cycleStart == 0) {
        protocol_execute_realtime();
    }
    sys_rt_exec_state.cycleStart = 0;

    // 4. 探测刀具长度
    float probe_target[MAX_N_AXIS] = {
        tool_change_pos[X_AXIS],
        tool_change_pos[Y_AXIS],
        TOOL_PROBE_Z,
    };

    sys_probe_state = Probe::Active;
    plan_data.condition = PlanLineFlag::IsProbeCycle;
    plan_data.feed_rate = 100;
    mc_line(probe_target, &plan_data, sys_position);
    protocol_buffer_synchronize();

    // 5. 设置刀具偏移
    if (sys_probe_state == Probe::Off) {
        float tool_length = sys_probe_position[Z_AXIS];
        gc_state.tool_length_offset = tool_length;

        grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info,
                      "Tool length: %.3f mm", tool_length);
    }

    // 6. 恢复运行
    sys.state = State::Idle;
}
```

## user_defined_homing - 自定义归零

**调用时机**：执行$H命令时，在标准归零之前

**用途**：非笛卡尔机器的归零、特殊归零序列

### 自定义示例

```cpp
bool user_defined_homing(uint8_t cycle_mask) {
    // 返回true表示使用自定义归零，跳过标准归零
    // 返回false表示使用标准归零

    // 示例：SCARA机器的归零
    if (MACHINE_TYPE == SCARA) {
        // 1. 归零关节1
        homing_joint(JOINT_1, cycle_mask);

        // 2. 归零关节2
        homing_joint(JOINT_2, cycle_mask);

        // 3. 计算笛卡尔坐标
        forward_kinematics();

        return true;  // 使用自定义归零
    }

    return false;  // 使用标准归零
}
```

## user_defined_macro - 宏按钮

**调用时机**：按下宏按钮时

**用途**：快捷操作、预定义命令序列

### 自定义示例

```cpp
void user_defined_macro(uint8_t index) {
    switch (index) {
        case 0:
            // 宏0：归零
            execute_line("$H", CLIENT_SERIAL);
            break;

        case 1:
            // 宏1：探测Z轴并设置零点
            execute_line("G38.2 Z-10 F100", CLIENT_SERIAL);
            execute_line("G92 Z0", CLIENT_SERIAL);
            execute_line("G0 Z5", CLIENT_SERIAL);
            break;

        case 2:
            // 宏2：回到工作原点
            execute_line("G90", CLIENT_SERIAL);
            execute_line("G0 X0 Y0", CLIENT_SERIAL);
            execute_line("G0 Z0", CLIENT_SERIAL);
            break;

        case 3:
            // 宏3：暂停并抬起Z轴
            sys_rt_exec_state.feedHold = 1;
            protocol_buffer_synchronize();
            execute_line("G91", CLIENT_SERIAL);
            execute_line("G0 Z5", CLIENT_SERIAL);
            execute_line("G90", CLIENT_SERIAL);
            break;
    }
}
```

## 运动学扩展

### cartesian_to_motors - 逆运动学

**调用时机**：每次运动规划时

**用途**：非笛卡尔机器的坐标转换

```cpp
// MotionControl.cpp
bool __attribute__((weak)) cartesian_to_motors(float* target,
                                                plan_line_data_t* pl_data,
                                                float* position) {
    // 返回false表示使用默认（笛卡尔）
    // 返回true表示已处理

    // 示例：CoreXY运动学
    if (MACHINE_TYPE == COREXY) {
        // CoreXY: A = X + Y, B = X - Y
        float a = target[X_AXIS] + target[Y_AXIS];
        float b = target[X_AXIS] - target[Y_AXIS];

        // 转换为电机步数
        target[X_AXIS] = a;
        target[Y_AXIS] = b;

        return true;  // 已处理
    }

    return false;  // 使用默认
}
```

### motors_to_cartesian - 正运动学

**调用时机**：位置报告时

**用途**：电机坐标转换为笛卡尔坐标

```cpp
void __attribute__((weak)) motors_to_cartesian(float* cartesian,
                                                float* motors,
                                                int n_axis) {
    // 默认：直接复制
    memcpy(cartesian, motors, n_axis * sizeof(float));

    // 示例：CoreXY
    if (MACHINE_TYPE == COREXY) {
        // X = (A + B) / 2, Y = (A - B) / 2
        cartesian[X_AXIS] = (motors[X_AXIS] + motors[Y_AXIS]) / 2.0;
        cartesian[Y_AXIS] = (motors[X_AXIS] - motors[Y_AXIS]) / 2.0;
    }
}
```

### kinematics_pre_homing - 归零前处理

```cpp
bool __attribute__((weak)) kinematics_pre_homing(uint8_t cycle_mask) {
    // 返回true表示可以归零
    // 返回false表示不能归零

    // 示例：检查机器状态
    if (check_machine_ready()) {
        return true;
    } else {
        grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Error,
                      "Machine not ready for homing");
        return false;
    }
}
```

### kinematics_post_homing - 归零后处理

```cpp
void __attribute__((weak)) kinematics_post_homing() {
    // 归零完成后的处理

    // 示例：移动到安全位置
    float safe_pos[MAX_N_AXIS] = {10, 10, 10};
    plan_line_data_t plan_data;
    plan_data.feed_rate = 1000;
    mc_line(safe_pos, &plan_data, sys_position);
    protocol_buffer_synchronize();
}
```

## 技术约束

### 1. 调用时机

- `machine_init()`: 在硬件初始化后
- `display_init()`: 在串口初始化后
- `user_m30()`: 在M30执行时
- 不能在ISR中调用

### 2. 阻塞限制

- 避免长时间阻塞
- 使用任务处理耗时操作
- 使用 `protocol_execute_realtime()` 保持响应

### 3. 内存限制

- 注意栈大小
- 避免大数组
- 使用动态分配时检查返回值

## 兼容性注意事项

### 1. 与核心代码协调

- 不要修改全局状态
- 使用提供的API
- 遵循命名约定

### 2. 多客户端支持

- 使用 `CLIENT_ALL` 广播消息
- 使用 `CLIENT_SERIAL` 发送到串口

### 3. 状态检查

```cpp
void user_m30() {
    // 检查状态
    if (sys.state != State::Idle) {
        return;
    }

    // 执行操作
    // ...
}
```
