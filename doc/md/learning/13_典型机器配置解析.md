# 典型机器配置解析

本文档通过分析几个典型的机器配置文件，帮助理解如何配置不同类型的CNC机器。

## 配置文件概览

Grbl_Esp32 提供了39个预定义的机器配置文件，涵盖各种硬件组合：

| 配置文件 | 类型 | 轴数 | 主轴 | 特点 |
|----------|------|------|------|------|
| [3axis_v4.h](../../Grbl_Esp32/src/Machines/3axis_v4.h) | 激光雕刻 | 3 | PWM | 基础配置 |
| [6_pack_stepstick_v1.h](../../Grbl_Esp32/src/Machines/6_pack_stepstick_v1.h) | CNC铣床 | 6 | PWM | 6轴支持 |
| [6_pack_trinamic_stallguard.h](../../Grbl_Esp32/src/Machines/6_pack_trinamic_stallguard.h) | CNC铣床 | 6 | PWM | Trinamic驱动 |
| [pen_laser.h](../../Grbl_Esp32/src/Machines/pen_laser.h) | 绘图机 | 3 | Laser | RC伺服Z轴 |
| [test_drive.h](../../Grbl_Esp32/src/Machines/test_drive.h) | 测试 | 3 | None | 无硬件 |

## 案例1：3axis_v4 - 基础3轴激光

**文件位置**：[Machines/3axis_v4.h](../../Grbl_Esp32/src/Machines/3axis_v4.h)

### 完整配置

```cpp
#pragma once
// clang-format off

#define MACHINE_NAME "ESP32_V4"

// ========== 轴引脚定义 ==========
#define X_STEP_PIN              GPIO_NUM_12
#define X_DIRECTION_PIN         GPIO_NUM_14
#define Y_STEP_PIN              GPIO_NUM_26
#define Y_DIRECTION_PIN         GPIO_NUM_15
#define Z_STEP_PIN              GPIO_NUM_27
#define Z_DIRECTION_PIN         GPIO_NUM_33

// ========== 限位开关 ==========
#define X_LIMIT_PIN             GPIO_NUM_17
#define Y_LIMIT_PIN             GPIO_NUM_4
#define Z_LIMIT_PIN             GPIO_NUM_16

// ========== 使能引脚 ==========
#define STEPPERS_DISABLE_PIN    GPIO_NUM_13

// ========== 主轴配置 ==========
#define SPINDLE_TYPE            SpindleType::PWM
#define SPINDLE_OUTPUT_PIN      GPIO_NUM_2
#define SPINDLE_ENABLE_PIN      GPIO_NUM_22

// ========== 辅助功能 ==========
#define COOLANT_MIST_PIN        GPIO_NUM_21
#define COOLANT_FLOOD_PIN       GPIO_NUM_25
#define PROBE_PIN               GPIO_NUM_32

// ========== 控制引脚（可选） ==========
// #define CONTROL_SAFETY_DOOR_PIN GPIO_NUM_35
// #define CONTROL_RESET_PIN       GPIO_NUM_34
// #define CONTROL_FEED_HOLD_PIN   GPIO_NUM_36
// #define CONTROL_CYCLE_START_PIN GPIO_NUM_39
```

### 配置解析

**1. 机器名称**
```cpp
#define MACHINE_NAME "ESP32_V4"
```
- 用于识别机器类型
- 显示在启动信息中

**2. 步进电机引脚**
```cpp
#define X_STEP_PIN              GPIO_NUM_12
#define X_DIRECTION_PIN         GPIO_NUM_14
```
- 每个轴需要2个引脚：步进脉冲和方向
- 使用 `GPIO_NUM_xx` 宏定义
- 避免使用启动引脚（GPIO 0, 2, 12, 15）

**3. 限位开关**
```cpp
#define X_LIMIT_PIN             GPIO_NUM_17
```
- 每个轴1个限位引脚
- 支持常开（NO）或常闭（NC）开关
- 通过 `$5` 设置反转

**4. 共享使能引脚**
```cpp
#define STEPPERS_DISABLE_PIN    GPIO_NUM_13
```
- 所有轴共享一个使能引脚
- 低电平有效（通常）
- 可通过 `$4` 设置反转

**5. PWM主轴**
```cpp
#define SPINDLE_TYPE            SpindleType::PWM
#define SPINDLE_OUTPUT_PIN      GPIO_NUM_2
#define SPINDLE_ENABLE_PIN      GPIO_NUM_22
```
- PWM输出控制转速
- 使能引脚控制开关
- 支持M3/M4/M5命令

**6. 冷却液**
```cpp
#define COOLANT_MIST_PIN        GPIO_NUM_21
#define COOLANT_FLOOD_PIN       GPIO_NUM_25
```
- 雾化冷却（M7）
- 液体冷却（M8）
- 可选功能

**7. 探针**
```cpp
#define PROBE_PIN               GPIO_NUM_32
```
- 用于G38探测
- 支持接触式探针
- 可选功能

### 引脚分配表

| 功能 | GPIO | 说明 |
|------|------|------|
| X步进 | 12 | 步进脉冲 |
| X方向 | 14 | 方向控制 |
| Y步进 | 26 | 步进脉冲 |
| Y方向 | 15 | 方向控制 |
| Z步进 | 27 | 步进脉冲 |
| Z方向 | 33 | 方向控制 |
| X限位 | 17 | 限位开关 |
| Y限位 | 4 | 限位开关 |
| Z限位 | 16 | 限位开关 |
| 使能 | 13 | 共享使能 |
| 主轴PWM | 2 | PWM输出 |
| 主轴使能 | 22 | 开关控制 |
| 雾化 | 21 | 冷却液 |
| 液体 | 25 | 冷却液 |
| 探针 | 32 | 探测输入 |

## 案例2：6_pack_trinamic_stallguard - Trinamic驱动

**文件位置**：[Machines/6_pack_trinamic_stallguard.h](../../Grbl_Esp32/src/Machines/6_pack_trinamic_stallguard.h)

### 关键配置

```cpp
#pragma once
// clang-format off

#define MACHINE_NAME "6 Pack Controller StallGuard"

// ========== Trinamic驱动配置 ==========
#define USE_TRINAMIC_SPI

// X轴 - TMC2130
#define X_TRINAMIC_DRIVER       2130
#define X_STEP_PIN              GPIO_NUM_12
#define X_DIRECTION_PIN         GPIO_NUM_14
#define X_DRIVER_CS_PIN         GPIO_NUM_17
#define X_RSENSE                0.11f
#define X_DRIVER_CURRENT        0.5f
#define X_DRIVER_MICROSTEPS     16

// Y轴 - TMC2130
#define Y_TRINAMIC_DRIVER       2130
#define Y_STEP_PIN              GPIO_NUM_26
#define Y_DIRECTION_PIN         GPIO_NUM_15
#define Y_DRIVER_CS_PIN         GPIO_NUM_21
#define Y_RSENSE                0.11f
#define Y_DRIVER_CURRENT        0.5f
#define Y_DRIVER_MICROSTEPS     16

// Z轴 - TMC2130
#define Z_TRINAMIC_DRIVER       2130
#define Z_STEP_PIN              GPIO_NUM_27
#define Z_DIRECTION_PIN         GPIO_NUM_33
#define Z_DRIVER_CS_PIN         GPIO_NUM_16
#define Z_RSENSE                0.11f
#define Z_DRIVER_CURRENT        0.5f
#define Z_DRIVER_MICROSTEPS     16

// ========== SPI配置 ==========
#define TRINAMIC_SPI_SCK        GPIO_NUM_18
#define TRINAMIC_SPI_MISO       GPIO_NUM_19
#define TRINAMIC_SPI_MOSI       GPIO_NUM_23

// ========== StallGuard配置 ==========
#define X_HOMING_MODE           TrinamicMode::StallGuard
#define Y_HOMING_MODE           TrinamicMode::StallGuard
#define Z_HOMING_MODE           TrinamicMode::StallGuard

#define X_STALLGUARD_THRESHOLD  10
#define Y_STALLGUARD_THRESHOLD  10
#define Z_STALLGUARD_THRESHOLD  10
```

### Trinamic配置解析

**1. 驱动类型**
```cpp
#define X_TRINAMIC_DRIVER       2130
```
- 2130: TMC2130（SPI）
- 5160: TMC5160（SPI）
- 2208: TMC2208（UART）
- 2209: TMC2209（UART）

**2. 感应电阻**
```cpp
#define X_RSENSE                0.11f
```
- 用于电流检测
- 典型值：0.11Ω 或 0.075Ω
- 查看驱动板原理图

**3. 电流设置**
```cpp
#define X_DRIVER_CURRENT        0.5f
```
- 单位：安培（A）
- 根据电机额定电流设置
- 通常设置为额定电流的70-80%

**4. 微步设置**
```cpp
#define X_DRIVER_MICROSTEPS     16
```
- 支持：1, 2, 4, 8, 16, 32, 64, 128, 256
- 更高微步=更平滑，但速度降低
- 推荐：16或32

**5. CS引脚**
```cpp
#define X_DRIVER_CS_PIN         GPIO_NUM_17
```
- SPI片选引脚
- 每个驱动独立CS引脚
- 共享SCK/MISO/MOSI

**6. StallGuard模式**
```cpp
#define X_HOMING_MODE           TrinamicMode::StallGuard
```
- StealthChop: 静音模式
- CoolStep: 冷却模式
- StallGuard: 堵转检测（无限位归零）

**7. StallGuard阈值**
```cpp
#define X_STALLGUARD_THRESHOLD  10
```
- 范围：-64 到 63
- 值越小越敏感
- 需要测试调整

### SPI总线配置

```cpp
#define TRINAMIC_SPI_SCK        GPIO_NUM_18
#define TRINAMIC_SPI_MISO       GPIO_NUM_19
#define TRINAMIC_SPI_MOSI       GPIO_NUM_23
```

**SPI连接**：
```
ESP32          TMC2130
GPIO18 (SCK)  → SCK
GPIO19 (MISO) ← SDO
GPIO23 (MOSI) → SDI
GPIO17 (CS)   → CS (X轴)
GPIO21 (CS)   → CS (Y轴)
GPIO16 (CS)   → CS (Z轴)
```

## 案例3：pen_laser - RC伺服Z轴

**文件位置**：[Machines/pen_laser.h](../../Grbl_Esp32/src/Machines/pen_laser.h)

### 关键配置

```cpp
#pragma once
// clang-format off

#define MACHINE_NAME "Pen/Laser"

// ========== X/Y轴：标准步进 ==========
#define X_STEP_PIN              GPIO_NUM_12
#define X_DIRECTION_PIN         GPIO_NUM_14

#define Y_STEP_PIN              GPIO_NUM_26
#define Y_DIRECTION_PIN         GPIO_NUM_15

// ========== Z轴：RC伺服 ==========
#define Z_SERVO_PIN             GPIO_NUM_27

// ========== 激光主轴 ==========
#define SPINDLE_TYPE            SpindleType::LASER
#define SPINDLE_OUTPUT_PIN      GPIO_NUM_2

// ========== RC伺服设置 ==========
#define DEFAULT_Z_MAX_TRAVEL    5.0   // mm
#define DEFAULT_Z_HOMING_MPOS   5.0   // mm

// 伺服校准（PWM脉冲宽度，微秒）
#define Z_SERVO_CAL_MIN         1000  // 最小位置
#define Z_SERVO_CAL_MAX         2000  // 最大位置
```

### RC伺服配置解析

**1. 伺服引脚**
```cpp
#define Z_SERVO_PIN             GPIO_NUM_27
```
- 输出PWM信号（50Hz）
- 脉冲宽度：1-2ms
- 控制伺服角度

**2. 行程设置**
```cpp
#define DEFAULT_Z_MAX_TRAVEL    5.0   // mm
```
- 虚拟行程（mm）
- 映射到伺服角度
- 用于G-code坐标

**3. 伺服校准**
```cpp
#define Z_SERVO_CAL_MIN         1000  // 1ms
#define Z_SERVO_CAL_MAX         2000  // 2ms
```
- 最小脉冲宽度（抬起）
- 最大脉冲宽度（放下）
- 根据实际伺服调整

**4. 激光主轴**
```cpp
#define SPINDLE_TYPE            SpindleType::LASER
```
- 支持M4速度补偿
- 进给保持时自动关闭
- 激光安全特性

### 工作原理

```
G-code坐标 → 伺服角度
Z0.0mm     → 1000μs (抬起)
Z2.5mm     → 1500μs (中间)
Z5.0mm     → 2000μs (放下)
```


## 常见配置问题

### 1. 引脚冲突

**问题**：两个功能使用同一引脚

**解决**：
```cpp
// 错误
#define X_STEP_PIN      GPIO_NUM_12
#define SPINDLE_OUTPUT_PIN GPIO_NUM_12  // 冲突！

// 正确
#define X_STEP_PIN      GPIO_NUM_12
#define SPINDLE_OUTPUT_PIN GPIO_NUM_2   // 不同引脚
```

### 2. 启动引脚问题

**问题**：使用GPIO 0, 2, 12, 15导致无法启动

**解决**：避免使用这些引脚，或添加外部上拉/下拉

### 3. 输入专用引脚

**问题**：GPIO 34, 35, 36, 39用作输出

**解决**：这些引脚只能用作输入（限位、探针等）

### 4. Trinamic通信失败

**问题**：TMC驱动不响应

**解决**：
- 检查SPI接线
- 检查CS引脚
- 检查电源
- 降低SPI速度
