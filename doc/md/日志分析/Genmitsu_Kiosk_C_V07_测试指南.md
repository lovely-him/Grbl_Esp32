## 故障排查

### 问题 1: 限位开关不触发

**可能原因**:
- 反转逻辑配置错误
- 限位开关硬件故障
- 引脚定义错误

**排查步骤**:
```bash
# 1. 检查启动日志
[MSG:X  Axis limit switch on pin GPIO(36)]
[MSG:Y  Axis limit switch on pin GPIO(35)]

# 2. 测试限位开关状态
?           # 查询状态
# 手动触发限位开关，再次查询
?           # 应该看到 Pn: 标志

# 3. 检查设置
$5=0        # 确认限位反转设置为 0
```

### 问题 2: 安全门不工作

**可能原因**:
- 引脚定义错误
- 反转逻辑配置错误
- 安全门功能未启用

**排查步骤**:
```bash
# 1. 检查启动日志
[MSG:Safety door on pin GPIO(17)]

# 2. 测试安全门状态
?           # 查询状态
# 打开盖子，再次查询
?           # 应该看到 Door 标志

# 3. 检查设置
$22=1       # 确认归零循环启用
```

### 问题 3: 风扇不转

**可能原因**:
- 引脚定义错误
- MOS 管驱动电路故障
- 风扇电源问题

**排查步骤**:
```bash
# 1. 检查启动日志
[MSG:Mist coolant on pin GPIO(16)]

# 2. 测试引脚输出
M7          # 开启风扇
# 用万用表测量 GPIO 16 电压，应该是 3.3V

M9          # 关闭风扇
# 再次测量，应该是 0V

# 3. 如果电压正常但风扇不转
# 检查 MOS 管驱动电路和风扇电源
```
