## 🔍 设备概述

Genmitsu Kiosk C V07 是一款基于 ESP32 的激光雕刻机控制器，采用 Grbl_ESP32 固件。该设备为紧凑型设计，仅支持 X 和 Y 两轴运动（Z 轴配置但无限位开关），配备激光主轴，支持 WiFi 连网和 Web 控制。

### 关键特性
- ✅ **2 轴运动**: X 轴和 Y 轴，工作行程约 100mm × 100mm
- ✅ **激光主轴**: 13-bit PWM 控制，5000Hz 频率
- ✅ **WiFi 连接**: 支持 STA 模式连接路由器
- ✅ **Web 控制**: 内置 HTTP 服务器和 Telnet (端口 8080)
- ✅ **安全功能**: 合盖检测开关
- ✅ **物理控制**: 开关机按钮、停止按钮
- ✅ **状态指示**: LED 指示灯（未连接时闪烁，连接后长亮）

## ⚙️ 运动控制参数

### 步进控制方式
- **方法**: RMT (Remote Control Transceiver) 步进输出
- **优点**: 高精度、低抖动、不占用 CPU 资源
- **电机驱动**: 标准步进驱动器 (Step/Dir 接口)

### 默认行程限制
```
X 轴: -2.000 ~ 98.000 mm (有效行程 100mm)
Y 轴: -2.000 ~ 98.000 mm (有效行程 100mm)
Z 轴: 0.000 ~ 1000.000 mm (虚拟轴，实际不使用)
```

**负行程说明**: X/Y 轴允许 -2mm 的负行程，这是为了提供归零后的缓冲区域，防止机械结构卡死。

### 关键 Grbl 设置参数 (需查询 $$ 命令获取完整配置)

预期的关键参数：

## 🔧 自定义初始化代码分析

### 日志中的调试信息
```
jk_chu_shi_hua
jk_chu_shi_hua2
```

**分析**:
- 这两条消息出现在网络初始化完成之后，限位引脚初始化之前
- "jk_chu_shi_hua" 可能是中文拼音 "激光初始化" 的缩写
- 这表明原始固件中可能有自定义的 `machine_init()` 函数
- **⚠️ 警告**: 这段代码可能包含不正确的 ISR 处理，导致了系统崩溃错误

### 可能的自定义代码位置

根据 Grbl_ESP32 架构，自定义初始化代码应该在机器配置文件中定义：

```cpp
// 在 Genmitsu_Kiosk_C_V07.h 中可能包含：
void machine_init() {
    // 自定义初始化代码
    // 可能包含 LED 控制、按钮初始化等

    Serial.println("jk_chu_shi_hua");   // ❌ 错误：不应该在这里输出
    Serial.println("jk_chu_shi_hua2");  // ❌ 错误：不应该在这里输出

    // 可能还包含了错误的 ISR 队列操作
    // 这导致了后续的 xQueueGenericSendFromISR 断言失败
}
```

**问题诊断**:
原始固件崩溃的原因很可能是在中断服务程序 (ISR) 中调用了不安全的函数，例如：
- 在 ISR 中使用 `xQueueSend()` 而不是 `xQueueSendFromISR()`
- 在 ISR 中调用 `Serial.print()`

## 📝 已知问题和限制

### 1. 系统崩溃错误
**错误日志**:
```
queue.c:1157 (xQueueGenericSendFromISR)- assert failed!
abort() was called at PC 0x4008ae0c on core 1
```

**原因分析**:
- 原始固件在 ISR 中使用了错误的 FreeRTOS 队列操作
- 可能在自定义的 `machine_init()` 或按钮中断处理函数中

**解决方案**:
- 新配置文件中移除可能导致问题的自定义代码
- 确保所有 ISR 函数使用 `xQueueSendFromISR()` 而不是 `xQueueSend()`
- 不在 ISR 中调用 `Serial.print()` 等阻塞函数

### 2. Z 轴配置但未使用
- 固件配置了 3 轴，但实际设备只有 2 轴
- Z 轴参数设置为 0-1000mm，但没有实际意义
- 建议保持 Z 轴配置以兼容 Grbl 标准，但不使用

### 3. 未确认的引脚配置
- 控制按钮引脚未知
- 状态 LED 引脚未知
- 需要硬件测试或固件反汇编确认
