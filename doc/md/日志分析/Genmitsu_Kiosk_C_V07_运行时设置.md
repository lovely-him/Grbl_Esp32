# Genmitsu Kiosk C V07 运行时设置配置指南

## 📋 文档说明

本文档用于在上传新固件后，通过串口命令恢复原厂的运行时设置参数。

**重要提示**：
- 编译时配置（引脚定义）在 `.h` 文件中
- 运行时设置（行程、速度、加速度等）存储在 EEPROM/NVS 中
- 运行时设置通过 `$` 命令配置

---

## 🔧 必须配置的参数

### 1. 行程限制设置

根据原厂日志，设备的行程限制为：

```gcode
$130=-2.000    ; X 轴最大行程 (mm) - 允许 -2mm 负行程作为缓冲区
$131=-2.000    ; Y 轴最大行程 (mm) - 允许 -2mm 负行程作为缓冲区
$132=1000.000  ; Z 轴最大行程 (mm) - 虚拟轴，实际不使用
```

**说明**：
- X/Y 轴的负行程（-2mm）是为了提供归零后的安全缓冲区
- 实际工作区域是 0 ~ 98mm（约 100mm × 100mm）
- Z 轴配置为 0-1000mm 但实际不使用

### 2. 激光模式设置

```gcode
$32=1    ; 启用激光模式 (Laser Mode)
```

**激光模式说明**：
- `$32=0`: 禁用激光模式（恒定功率）
- `$32=1`: 启用激光模式（动态功率调制）
- 激光模式下，激光功率会根据运动速度自动调整
- 适用于矢量雕刻和填充雕刻

### 3. 主轴/激光功率范围

```gcode
$30=1000    ; 最大主轴转速/激光功率 (RPM 或百分比)
$31=0       ; 最小主轴转速/激光功率
```

**说明**：
- 对于激光，`$30` 表示 100% 功率对应的数值
- S 命令范围：S0 ~ S1000 对应 0% ~ 100% 功率
- 例如：`M3 S500` = 50% 激光功率

## 📊 推荐配置的参数

以下参数需要根据实际机器调整，这里提供参考值：

### 4. 步进参数

```gcode
$100=80.0    ; X 轴步进/mm (steps per mm) - 需根据实际机械结构调整
$101=80.0    ; Y 轴步进/mm
$102=80.0    ; Z 轴步进/mm (虚拟轴)
```

**如何计算**：
```
步进/mm = (电机步距角 / 360°) × 细分数 × (传动比) / 同步带节距
例如：1.8° 电机，16 细分，GT2 同步带（2mm 节距），20 齿轮
= (1.8/360) × 16 × 1 / (20 × 2) = 80 步/mm
```

### 5. 最大速度

```gcode
$110=5000.0    ; X 轴最大速度 (mm/min)
$111=5000.0    ; Y 轴最大速度 (mm/min)
$112=5000.0    ; Z 轴最大速度 (mm/min)
```

**说明**：
- 5000 mm/min = 83.3 mm/s
- 激光雕刻推荐速度：1000-3000 mm/min
- 快速移动速度：3000-5000 mm/min

### 6. 加速度

```gcode
$120=500.0    ; X 轴加速度 (mm/sec²)
$121=500.0    ; Y 轴加速度 (mm/sec²)
$122=500.0    ; Z 轴加速度 (mm/sec²)
```

**说明**：
- 加速度越大，启停越快，但可能丢步
- 加速度越小，运动越平滑，但速度慢
- 推荐从 300-500 mm/sec² 开始测试

### 7. 限位开关配置

```gcode
$5=0    ; 限位引脚反转 (0=常开NO, 1=常闭NC)
$21=1   ; 启用硬限位 (0=禁用, 1=启用)
$22=1   ; 启用归零循环 (0=禁用, 1=启用)
$23=0   ; 归零方向反转掩码 (0=正向归零)
```

**限位开关类型判断**：
- 如果限位开关未触发时显示 "触发"，设置 `$5=1`
- 如果限位开关触发时显示 "未触发"，设置 `$5=0`

### 8. 步进电机配置

```gcode
$0=10     ; 步进脉冲时间 (μs)
$1=255    ; 步进空闲延迟 (ms) - 255 表示永不失能
$2=0      ; 步进端口反转掩码
$3=0      ; 方向端口反转掩码
$4=0      ; 步进使能反转 (0=低电平使能, 1=高电平使能)
```

**方向反转说明**：
- 如果某个轴运动方向相反，修改 `$3`
- `$3=0`: 所有轴正常
- `$3=1`: X 轴反转 (二进制 001)
- `$3=2`: Y 轴反转 (二进制 010)
- `$3=4`: Z 轴反转 (二进制 100)
- `$3=3`: X 和 Y 轴反转 (二进制 011)

### 9. 软限位

```gcode
$20=0    ; 软限位使能 (0=禁用, 1=启用)
```

**说明**：
- 软限位需要先进行归零 (`$H`)
- 启用后，超出 `$130/$131/$132` 范围的运动会被拒绝
- 建议先禁用，测试完成后再启用

## 🔍 验证配置

### 1. 查看所有设置

```gcode
$$
```

这会显示所有当前设置参数。

### 2. 查看启动信息

```gcode
$I
```

应该显示：
```
[MSG:Grbl_ESP32 Ver 1.3a Date 20211103]
[MSG:Using machine:Genmitsu_Kiosk_C_V07_HIM]
[MSG:Laser spindle on Pin:GPIO(21), Enbl:None, Freq:5000Hz, Res:13bits Laser mode:On]
```

### 3. 测试限位开关

```gcode
?
```

在状态报告中查看 `Pn:` 字段：
- `Pn:` 为空 = 所有限位开关未触发
- `Pn:X` = X 轴限位触发
- `Pn:Y` = Y 轴限位触发
- `Pn:XY` = X 和 Y 轴限位同时触发

手动触发限位开关，观察状态变化。

### 4. 测试激光输出（小心！）

```gcode
$X          ; 解锁
M3 S100     ; 启动激光，10% 功率（非常低功率，用于测试）
M5          ; 关闭激光
```

**安全警告**：
- 即使是低功率也要佩戴激光防护眼镜
- 确保激光不对准人或易燃物
- 测试时间不要超过 1-2 秒

## 🛠️ 常见问题排查

### 问题 1: 激光不工作

**检查清单**：
1. 确认日志显示：`[MSG:Laser spindle on Pin:GPIO(21)...]`
2. 确认激光模式已启用：`$32=1`
3. 检查激光功率范围：`$30=1000`, `$31=0`
4. 测试命令：`M3 S500`（50% 功率）

### 问题 2: 轴运动方向相反

**解决方案**：
修改 `$3` 参数反转方向：
- X 轴反转：`$3=1`
- Y 轴反转：`$3=2`
- X 和 Y 都反转：`$3=3`

### 问题 3: 限位开关状态异常

**解决方案**：
1. 发送 `?` 查看 `Pn:` 状态
2. 如果未触发时显示触发，设置 `$5=1`
3. 如果触发时显示未触发，设置 `$5=0`

### 问题 4: 归零失败

**检查清单**：
1. 确认限位开关已连接：X(GPIO36), Y(GPIO35)
2. 确认限位开关极性正确：`$5=0` 或 `$5=1`
3. 确认归零已启用：`$22=1`
4. 手动触发限位开关，观察 `?` 命令的 `Pn:` 状态

### 问题 5: 电机不转或抖动

**可能原因**：
1. 步进/mm 设置错误：检查 `$100`, `$101`, `$102`
2. 加速度过大：降低 `$120`, `$121`, `$122`
3. 最大速度过大：降低 `$110`, `$111`, `$112`
4. 电机驱动器电流过小：调整驱动器电位器

## 📚 参考命令

### 基本命令

| 命令 | 说明 |
|------|------|
| `$$` | 查看所有设置 |
| `$I` | 查看固件信息 |
| `$#` | 查看坐标系统和偏移 |
| `?` | 查看实时状态 |
| `$H` | 归零（Homing） |
| `$X` | 解锁（清除报警） |
| `$RST=$` | 恢复默认设置 |
| `$RST=#` | 清除坐标系统 |
| `$RST=*` | 恢复所有默认值并清除坐标 |

### G-code 命令

| 命令 | 说明 |
|------|------|
| `G0 X10 Y10` | 快速移动到 (10, 10) |
| `G1 X20 Y20 F1000` | 直线插补，速度 1000 mm/min |
| `M3 S500` | 启动主轴/激光，50% 功率 |
| `M4 S500` | 启动激光（动态功率模式） |
| `M5` | 关闭主轴/激光 |
| `G28` | 返回预定义位置 |
| `G30` | 返回预定义位置 2 |

## ⚠️ 重要提示

1. **首次测试**：
   - 先不连接激光，测试电机运动
   - 确认所有轴运动方向正确
   - 测试限位开关功能
   - 最后再测试激光输出

2. **激光安全**：
   - 始终佩戴激光防护眼镜
   - 确保合盖开关正常工作
   - 测试时使用低功率（S100-S200）
   - 不要长时间连续运行激光

3. **参数调整**：
   - 每次只修改一个参数
   - 修改后立即测试效果
   - 记录所有修改的参数值
   - 找到最佳参数后保存备份

4. **备份设置**：
   - 发送 `$$` 命令
   - 复制所有输出到文本文件
   - 保存为 "Genmitsu_Settings_Backup.txt"
   - 以后可以通过复制粘贴恢复
