## 1. 概述摘要

### 1.1 关键发现

本次分析针对文件传输测试期间发生的 ESP32 系统崩溃进行了深入调查。通过对 144,440 行日志的分析，识别出以下关键信息：

**崩溃统计**:
- **致命崩溃次数**: 2 次
- **崩溃时间**:
  - 第 1 次: 2026-01-31 22:25:43 (日志第 48872 行)
  - 第 2 次: 2026-02-01 04:16:03 (日志第 109062 行)
- **崩溃间隔**: 约 5 小时 50 分钟
- **Backtrace 特征**: 两次崩溃的调用栈完全相同

**非崩溃错误**:
- "No SD Card" 错误: 1,313 条（预期行为，设备未插入 SD 卡）
- TILT 传感器错误: 1 条（轻微问题）

### 1.2 根本原因（简述）

**SSDP 服务在定时器中断上下文中尝试分配大内存块失败，导致 `std::bad_alloc` 异常未被捕获，触发 `std::terminate()` 和 `abort()`。**

具体触发链：
```
SSDP 定时器触发 (每秒)
  → _update() 调用 WiFiUDP::parsePacket()
    → parsePacket() 尝试分配 1460 字节缓冲区 (new char[1460])
      → 内存分配失败 (堆碎片化/内存不足)
        → 抛出 std::bad_alloc 异常
          → 异常未被捕获
            → std::terminate() → abort()
```

### 1.3 影响范围

- **触发条件**: 文件传输服务器接收大文件（10MB）时，系统内存处于高压状态
- **崩溃模式**: 确定性崩溃（相同的调用栈，相同的触发条件）
- **系统状态**: 崩溃前内存显示 Free=24-38KB，Min=20-21KB，MaxAlloc=20KB
- **业务影响**: 系统完全重启，文件传输中断

### 1.4 解决方案（简述）

推荐采用以下组合方案：
1. **立即修复**: 在 SSDP 的 `_update()` 函数中添加异常捕获
2. **优化内存**: 使用静态缓冲区替代动态分配
3. **降低风险**: 在文件传输期间暂停 SSDP 服务
4. **长期优化**: 增加堆内存预留，优化内存分配策略

## 4. 根本原因

### 4.1 直接原因

**WiFiUDP::parsePacket() 在内存压力下分配 1460 字节失败，抛出未捕获的 `std::bad_alloc` 异常，触发系统终止。**

### 4.2 触发条件

1. **内存压力**: Free=36-38KB, MaxAlloc=20KB
2. **堆碎片化**: 虽然有足够空闲内存，但最大连续块不足
3. **文件传输活动**: 大量网络缓冲区分配/释放加剧碎片化
4. **SSDP 定时器**: 每秒触发，在内存压力下触发分配失败

### 4.3 已知问题确认

✅ **这是 Arduino ESP32 WiFiUDP 库的已知设计缺陷**

**证据**:
- [ESP32SSDP Issue #26](https://github.com/luc-github/ESP32SSDP/issues/26): 相同的 `std::bad_alloc` 崩溃，维护者已实施 try-catch 修复
- [arduino-esp32 Issue #4104](https://github.com/espressif/arduino-esp32/issues/4104): parsePacket() 崩溃，有官方 PR #7847（未合并）
- [arduino-esp32 Issue #2871](https://github.com/espressif/arduino-esp32/issues/2871): 频繁调用导致内存问题

**结论**:
- ❌ 无法通过配置避免（WiFiUDP 无配置选项）
- ✅ 必须修改源代码添加异常捕获
- 🟡 长期方案：迁移到 AsyncUDP

## 5. 修复实施

### 5.1 修复方案

**修改文件**: `libraries/ESP32SSDP/ESP32SSDP.cpp`

**修改位置**: `_update()` 函数（第 245-277 行）

**修改内容**:
```cpp
void SSDPClass::_update(){
  int nbBytes  =0;
  char * packetBuffer = nullptr;

  if(!_pending && _server) {
    ssdp_method_t method = NONE;

    // 添加异常捕获 - 防止 WiFiUDP::parsePacket() 内存分配失败导致崩溃
    // 参考: https://github.com/luc-github/ESP32SSDP/issues/26
    try {
      nbBytes= _server->parsePacket();
    } catch (const std::bad_alloc& e) {
      log_e("[SSDP] Memory allocation failed in parsePacket(): %s", e.what());
      return;  // 安全返回，不崩溃
    }

    // ... 其他代码 ...

    // 添加第二个异常捕获 - 防止数据包缓冲区分配失败
    try {
      packetBuffer = new char[nbBytes +1];
    } catch (const std::bad_alloc& e) {
      log_e("[SSDP] Memory allocation failed for packet buffer (%d bytes): %s", nbBytes+1, e.what());
      return;  // 安全返回
    }

    // ... 继续处理 ...
  }
}
```
