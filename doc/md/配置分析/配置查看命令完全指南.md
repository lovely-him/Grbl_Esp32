# Grbl_Esp32 配置查看命令完全指南

## 概述

Grbl_Esp32 提供了多种命令用于查看系统配置、运行状态和固件信息。本文档详细说明如何使用这些命令对比原厂固件和自编译固件的参数差异。

---

## 配置命令分类

### 1. Grbl 标准命令（$ 开头）

这些是经典 Grbl 的标准命令，与 AVR Grbl 兼容：

| 命令 | 名称 | 功能 | 状态限制 |
|------|------|------|----------|
| `$$` | 查看所有设置 | 显示所有 $xxx 参数 | 不能在运行/暂停时 |
| `$#` | 查看坐标系统 | 显示工作坐标偏移 | 仅空闲或报警时 |
| `$G` | 查看解析器状态 | 显示当前 G-code 模式 | 任何状态 |
| `$I` | 查看构建信息 | 显示固件版本和功能 | 仅空闲或报警时 |
| `$N` | 查看启动块 | 显示开机自动运行的 G-code | 仅空闲或报警时 |
| `$H` | 归零 | 执行归零循环 | 仅空闲或报警时 |
| `$X` | 解除报警 | 清除报警状态 | 仅报警时 |
| `$RST=$` | 恢复默认设置 | 重置所有参数到默认值 | 仅空闲或报警时 |
| `$RST=#` | 清除坐标偏移 | 清除所有工作坐标系 | 仅空闲或报警时 |
| `$RST=*` | 全部重置 | 恢复出厂设置 | 仅空闲或报警时 |

### 2. ESP3D 扩展命令（[ESPxxx] 格式）

这些是 Grbl_Esp32 特有的扩展命令，用于 WiFi/蓝牙配置：

| 命令 | 功能 | 权限 |
|------|------|------|
| `[ESP400]` | 查看所有 ESP3D 设置 | 用户/管理员 |
| `[ESP420]` | 查看当前 ESP3D 状态 | 用户/管理员 |
| `[ESP800]` | 查看固件信息 | 任何人 |

| `$13` | 报告单位 | 0=毫米，1=英寸 | 布尔 |
| `$20` | 软限位 | 启用软件限位检查 | 布尔 |

| `$23` | 归零方向 | 归零方向，位掩码 | 位掩码 |
| `$24` | 归零进给速度 | 归零时的快速移动速度 | 毫米/分 |
| `$25` | 归零寻找速度 | 归零时的精确定位速度 | 毫米/分 |

| `$30` | 最大主轴转速 | 主轴最高 RPM | RPM |
| `$31` | 最小主轴转速 | 主轴最低 RPM | RPM |
| `$32` | 激光模式 | 启用激光模式（速度调制） | 布尔 |
| `$33` | 主轴 PWM 频率 | PWM 输出频率 | Hz |

#### 轴特定设置（$100-$132）

每个轴有 3 个参数：`$1x0`（步数）、`$1x1`（速度）、`$1x2`（加速度）、`$1x3`（最大行程）

**X 轴（x=0）**:
- `$100` - X 轴步数/毫米
- `$110` - X 轴最大速度（毫米/分）
- `$120` - X 轴加速度（毫米/秒²）
- `$130` - X 轴最大行程（毫米）

**Y 轴（x=1）**:
- `$101` - Y 轴步数/毫米
- `$111` - Y 轴最大速度（毫米/分）
- `$121` - Y 轴加速度（毫米/秒²）
- `$131` - Y 轴最大行程（毫米）

**Z 轴（x=2）**:
- `$102` - Z 轴步数/毫米
- `$112` - Z 轴最大速度（毫米/分）
- `$122` - Z 轴加速度（毫米/秒²）
- `$132` - Z 轴最大行程（毫米）

**关键**: 对于 Genmitsu Kiosk C V07：
```
$5=0          ; 限位开关反转=0（常闭开关）
$23=7         ; 归零方向=7（X/Y/Z 正向归零）
$32=1         ; 激光模式=1（启用）
$130=100.000  ; X 轴行程=100mm
$131=100.000  ; Y 轴行程=100mm
```

### 2. `$#` - 查看坐标系统

**用途**: 显示所有工作坐标系偏移值

**执行方法**:
```
$#
```

**输出示例**:
```
[G54:0.000,0.000,0.000]
[G55:0.000,0.000,0.000]
[G56:0.000,0.000,0.000]
[G57:0.000,0.000,0.000]
[G58:0.000,0.000,0.000]
[G59:0.000,0.000,0.000]
[G28:0.000,0.000,0.000]
[G30:0.000,0.000,0.000]
[G92:0.000,0.000,0.000]
[TLO:0.000]
[PRB:0.000,0.000,0.000:0]
```

**说明**:
- **G54-G59**: 6 个持久化工作坐标系
- **G28**: 参考点 1（通过 G28.1 设置）
- **G30**: 参考点 2（通过 G30.1 设置）
- **G92**: 临时坐标偏移（非持久化）
- **TLO**: 刀具长度偏移
- **PRB**: 探针位置（最后一次探测结果，末尾 :1 表示成功）

**常用操作**:
```gcode
G10 L2 P1 X10 Y20 Z0  ; 设置 G54 偏移为 (10, 20, 0)
G54                   ; 切换到 G54 坐标系
G92 X0 Y0 Z0          ; 设置当前位置为工作原点（临时）
G92.1                 ; 清除 G92 偏移
```

### 3. `$G` - 查看解析器状态

**用途**: 显示当前 G-code 模式和设置

**执行方法**:
```
$G
```

**输出示例**:
```
[GC:G0 G54 G17 G21 G90 G94 M5 M9 T0 F0 S0]
```

**解析**:

| 组 | 代码 | 说明 |
|---|------|------|
| 运动 | `G0` | 快速移动（或 G1/G2/G3） |
| 坐标系 | `G54` | 工作坐标系（G54-G59） |
| 平面 | `G17` | XY 平面（或 G18/G19） |
| 单位 | `G21` | 毫米（或 G20 英寸） |
| 距离 | `G90` | 绝对坐标（或 G91 增量） |
| 进给 | `G94` | 单位/分钟（或 G93 反时间） |
| 主轴 | `M5` | 主轴停止（或 M3/M4） |
| 冷却液 | `M9` | 冷却液关（或 M7/M8） |
| 刀具 | `T0` | 当前刀具号 |
| 进给速度 | `F0` | 当前进给速度 |
| 主轴转速 | `S0` | 当前主轴转速 |

**常见组合**:
```
G0 G54 G17 G21 G90 G94 M5 M9  ; 空闲状态（激光关闭）
G1 G54 G17 G21 G90 G94 M3 M7  ; 切削中（主轴开，冷却液开）
```

### 4. `$I` - 查看构建信息

**用途**: 显示固件版本、编译日期和已启用的功能

**执行方法**:
```
$I
```

**输出示例**:
```
[VER:1.3a.20211103:Genmitsu_Kiosk_C_V07_HIM]
[OPT:VHMLSW,15,255,8191]
[MSG:Mode=STA:SSID=MT3000:Status=Connected:IP=192.168.1.100:MAC=XX-XX-XX-XX-XX-XX]
```

**解析**:

#### 第一行：版本信息
```
[VER:1.3a.20211103:Genmitsu_Kiosk_C_V07_HIM]
```
- **1.3a**: Grbl_ESP32 版本号
- **20211103**: 构建日期（2021年11月3日）
- **Genmitsu_Kiosk_C_V07_HIM**: 机器配置文件名

#### 第二行：编译选项
```
[OPT:VHMLSW,15,255,8191]
```

**字母标志**（已启用的功能）:
- `V` - 变量主轴（PWM 或激光）
- `M` - 冷却液雾化（Mist）
- `P` - 停车功能
- `H` - 单轴归零命令
- `L` - 限位开关（每轴两个）
- `A` - 探测时允许进给覆盖
- `B` - 蓝牙
- `S` - SD 卡
- `R` - 停车覆盖控制
- `W` - WiFi

**数字参数**:
- **15**: 块缓冲区数量（运动规划器缓冲区）
- **255**: RX 缓冲区大小（串口接收）
- **8191**: PWM 分辨率（13 位，0-8191）

#### 第三行：WiFi 状态（如果启用）
```
[MSG:Mode=STA:SSID=MT3000:Status=Connected:IP=192.168.1.100:MAC=XX-XX-XX-XX-XX-XX]
```
- **Mode=STA**: WiFi 模式（STA 客户端或 AP 热点）
- **SSID=MT3000**: 连接的网络名称
- **Status=Connected**: 连接状态
- **IP=192.168.1.100**: 分配的 IP 地址
- **MAC=XX-XX-XX**: MAC 地址

## 对比原厂固件和自编译固件

### 完整对比流程

#### 步骤 1: 连接原厂固件

```bash
# 使用串口工具连接设备（如 PuTTY, Arduino Serial Monitor）
# 波特率: 115200
# 端口: COM3（根据实际情况）
```

#### 步骤 2: 保存原厂配置

执行以下命令并保存输出：

```
# 1. 保存所有 Grbl 设置
$$

# 2. 保存坐标系统
$#

# 3. 保存解析器状态
$G

# 4. 保存构建信息
$I

# 5. 保存 ESP3D 设置
[ESP400]

# 6. 保存 ESP3D 状态
[ESP420]

# 7. 保存固件信息
[ESP800]
```

**建议**: 将所有输出复制到文本文件，命名为 `original_config.txt`

#### 步骤 3: 刷入自编译固件

```bash
# 使用 PlatformIO 或 esptool.py 刷入
pio run --target upload

# 或
esptool.py --chip esp32 --port COM3 write_flash 0x10000 firmware.bin
```

#### 步骤 4: 获取自编译固件配置

重新连接串口，执行相同命令：

```
$$
$#
$G
$I
[ESP400]
[ESP420]
[ESP800]
```

保存输出到 `compiled_config.txt`

#### 步骤 5: 对比差异

**关键对比项**:

1. **版本号** (`$I` 第一行)
   ```
   原厂: [VER:1.3a.20211103:Genmitsu_Kiosk_C_V07]
   自编: [VER:1.3a.20260115:Genmitsu_Kiosk_C_V07_HIM]
   ```
   - 检查日期是否不同（正常）
   - 检查机器名称是否匹配

2. **编译选项** (`$I` 第二行)
   ```
   原厂: [OPT:VHMLSW,15,255,8191]
   自编: [OPT:VHMLSW,15,255,8191]
   ```
   - 确保功能标志完全一致
   - 确保数字参数相同

3. **运动参数** (`$$` 中的轴设置)
   ```
   $100=800.000  ; X 轴步数/毫米
   $101=800.000  ; Y 轴步数/毫米
   $110=1000.000 ; X 轴最大速度
   $111=1000.000 ; Y 轴最大速度
   $120=50.000   ; X 轴加速度
   $121=50.000   ; Y 轴加速度
   $130=100.000  ; X 轴最大行程
   $131=100.000  ; Y 轴最大行程
   ```
   - **这些参数必须完全匹配**

4. **限位和归零** (`$$` 中的控制参数)
   ```
   $5=0    ; 限位开关反转
   $21=0   ; 硬限位（通常禁用）
   $22=1   ; 归零循环（启用）
   $23=7   ; 归零方向（X/Y/Z 正向）
   ```
   - **$5 和 $23 必须匹配**

5. **激光模式** (`$$` 中的主轴参数)
   ```
   $30=1000  ; 最大主轴转速
   $31=0     ; 最小主轴转速
   $32=1     ; 激光模式（必须为 1）
   $33=5000.000  ; PWM 频率
   ```
   - **$32 和 $33 必须匹配**

### 自动对比脚本

#### Python 脚本

```python
import serial
import time
import difflib

def get_all_settings(port):
    """读取所有设置"""
    ser = serial.Serial(port, 115200, timeout=2)
    time.sleep(2)

    settings = {}
    commands = [
        ("grbl_settings", "$$"),
        ("coord_systems", "$#"),
        ("parser_state", "$G"),
        ("build_info", "$I"),
        ("esp_settings", "[ESP400]"),
        ("esp_status", "[ESP420]"),
        ("fw_info", "[ESP800]")
    ]

    for name, cmd in commands:
        ser.write((cmd + "\n").encode())
        time.sleep(0.5)
        output = ser.read_all().decode()
        settings[name] = output

    ser.close()
    return settings

def compare_settings(original, compiled):
    """对比两个配置"""
    print("=" * 60)
    print("配置对比报告")
    print("=" * 60)

    for key in original.keys():
        print(f"\n### {key.upper()} ###\n")

        orig_lines = original[key].splitlines()
        comp_lines = compiled[key].splitlines()

        diff = list(difflib.unified_diff(
            orig_lines,
            comp_lines,
            lineterm='',
            fromfile='原厂',
            tofile='自编'
        ))

        if diff:
            for line in diff:
                if line.startswith('-'):
                    print(f"\033[91m{line}\033[0m")  # 红色
                elif line.startswith('+'):
                    print(f"\033[92m{line}\033[0m")  # 绿色
                else:
                    print(line)
        else:
            print("✓ 完全一致")

# 使用示例
original = get_all_settings("COM3")  # 原厂固件
# 刷入自编译固件，重新连接
compiled = get_all_settings("COM3")  # 自编译固件

compare_settings(original, compiled)
```

## 常见差异和解决方法

### 1. 版本号不同

**现象**:
```
原厂: [VER:1.3a.20211103:Genmitsu_Kiosk_C_V07]
自编: [VER:1.3a.20260115:Genmitsu_Kiosk_C_V07_HIM]
```

**原因**: 构建日期不同（正常）

**解决**: 无需处理，日期差异正常

---

### 2. 机器名称不匹配

**现象**:
```
原厂: Genmitsu_Kiosk_C_V07
自编: test_machine
```

**原因**: `Machine.h` 中的 `MACHINE_FILENAME` 配置错误

**解决**: 修改 `Grbl_Esp32/src/Machine.h`:
```cpp
#define MACHINE_FILENAME "Machines/Genmitsu_Kiosk_C_V07_HIM.h"
```

---

### 3. 功能标志不同

**现象**:
```
原厂: [OPT:VHMLSW,15,255,8191]
自编: [OPT:VML,15,255,8191]
```

**原因**: 编译选项配置不同

**解决**: 检查 `Config.h` 中的定义:
```cpp
#define ENABLE_WIFI              // 需要 W 标志
#define COOLANT_MIST_PIN         // 需要 M 标志
#define HOMING_SINGLE_AXIS_COMMANDS  // 需要 H 标志
```

---

### 4. PWM 分辨率不同

**现象**:
```
原厂: [OPT:VHMLSW,15,255,8191]
自编: [OPT:VHMLSW,15,255,255]
```

**原因**: 激光 PWM 位数配置错误

**解决**: 在机器配置文件中定义:
```cpp
#define SPINDLE_PWM_BIT_PRECISION 13  // 13 位 = 0-8191
```

或在 `Config.h` 中检查：
```cpp
#define DEFAULT_LASER_PWM_BIT_PRECISION 13
```

---

### 5. 步数/速度参数不同

**现象**:
```
原厂: $100=800.000
自编: $100=250.000
```

**原因**: 机器配置文件中的默认值不同

**解决方法 1**: 修改机器配置文件
```cpp
#define DEFAULT_X_STEPS_PER_MM 800.0
#define DEFAULT_Y_STEPS_PER_MM 800.0
```

**解决方法 2**: 通过串口手动设置
```
$100=800
$101=800
$110=1000
$111=1000
```

---

### 6. 限位反转设置不同

**现象**:
```
原厂: $5=0
自编: $5=1
```

**原因**:
- 原厂使用常闭开关，`$5=0`
- 自编使用默认值（常开开关），`$5=1`

**解决**: 在机器配置文件中添加:
```cpp
#define DEFAULT_INVERT_LIMIT_PINS 0  // 0=常闭开关
```

---

### 7. 归零方向不同

**现象**:
```
原厂: $23=7  (0b00000111 - X/Y/Z 正向)
自编: $23=0  (0b00000000 - X/Y/Z 负向)
```

**原因**: 默认值配置错误

**解决**: 在机器配置文件中添加:
```cpp
#define DEFAULT_HOMING_DIR_MASK 7  // bit0=X, bit1=Y, bit2=Z, 1=正向
```

---

### 8. 激光模式未启用

**现象**:
```
原厂: $32=1
自编: $32=0
```

**原因**: 激光模式默认值未设置

**解决**: 在机器配置文件中添加:
```cpp
#define DEFAULT_LASER_MODE 1  // 启用激光模式
```

## 配置导出和导入

### 导出配置到文件

#### 方法 1: 手动保存

1. 执行 `$$` 命令
2. 复制所有输出
3. 保存为 `settings.txt`

#### 方法 2: Python 脚本

```python
import serial
import time

def export_settings(port, filename):
    ser = serial.Serial(port, 115200, timeout=2)
    time.sleep(2)

    with open(filename, 'w') as f:
        # 获取所有设置
        ser.write(b"$$\n")
        time.sleep(0.5)
        f.write(ser.read_all().decode())

        # 获取坐标系统
        ser.write(b"$#\n")
        time.sleep(0.5)
        f.write(ser.read_all().decode())

        # 获取构建信息
        ser.write(b"$I\n")
        time.sleep(0.5)
        f.write(ser.read_all().decode())

    ser.close()
    print(f"配置已保存到 {filename}")

# 使用
export_settings("COM3", "original_settings.txt")
```

### 导入配置

#### 方法 1: 手动设置

从 `settings.txt` 中逐行复制参数：

```
$100=800
$101=800
$110=1000
...
```

#### 方法 2: Python 脚本

```python
import serial
import time
import re

def import_settings(port, filename):
    ser = serial.Serial(port, 115200, timeout=2)
    time.sleep(2)

    with open(filename, 'r') as f:
        for line in f:
            line = line.strip()
            # 只发送 $xxx=yyy 格式的行
            if re.match(r'^\$\d+=', line):
                print(f"设置: {line}")
                ser.write((line + "\n").encode())
                time.sleep(0.2)
                response = ser.read_all().decode()
                if "ok" not in response:
                    print(f"  错误: {response}")
                else:
                    print("  ✓")

    ser.close()
    print("配置导入完成")

# 使用
import_settings("COM3", "original_settings.txt")
```

## 故障排除

### 问题 1: 执行 $$ 无响应

**可能原因**:
- 波特率不匹配
- 设备正在运行 G-code

**解决**:
```
# 1. 检查波特率（Grbl_ESP32 默认 115200）
# 2. 发送 Ctrl-X (0x18) 软复位
# 3. 重新执行 $$
```

### 问题 2: 参数设置不生效

**现象**:
```
$100=800
ok
$$
$100=250.000  ; 仍然是旧值
```

**原因**: 参数未写入 NVS（非易失性存储）

**解决**:
```
# 1. 重启设备
[ESP444]RESTART

# 2. 重新检查
$$
$100=800.000  ; 应该已更新
```

### 问题 3: ESP3D 命令不可用

**现象**:
```
[ESP400]
error: Invalid statement
```

**原因**: WiFi 或蓝牙未启用

**解决**: 检查 `Config.h`:
```cpp
#define ENABLE_WIFI  // 或 #define ENABLE_BLUETOOTH
```
