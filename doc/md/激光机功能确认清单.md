## 一、产品概述

### 1.1 机器型号
- **产品名称**: Genmitsu Kiosk C V07 激光雕刻机
- **内部型号**: Wainlux K11 HIM
- **控制器**: ESP32 双核处理器 (240MHz)
- **固件版本**: Grbl_ESP32 V1.3a (定制版)

### 1.2 基本参数
| 项目 | 规格 |
|-----|------|
| 工作区域 | 100mm × 100mm |
| 轴数 | 2 轴 (X/Y) + 1 轴预留 (Z) |
| 激光主轴 | PWM 控制，5kHz，13 位分辨率 (0-8191) |
| 步进电机 | X/Y 轴，100 步/mm |

| 加速度 | X: 800 mm/s², Y: 240 mm/s² |
| 限位开关 | X/Y 轴，常闭型 |
| 归零方式 | 双轴同时归零，回退距离 2mm |

## 二、核心功能详解

### 2.1 用户交互

#### 2.1.1 按钮多功能控制（GPIO_NUM_19）

**硬件特性**：
- 常闭开关（NC - Normally Closed）
- 正常状态：高电平（内部上拉）
- 按下状态：低电平（接地）
- 防抖周期：50ms

**功能说明**：
按钮支持三种按压时长，根据机器当前状态执行不同操作。

##### 短按功能（< 0.5 秒）

| 机器状态 | 按钮功能 | 执行动作 | 用户体验 |
|---------|---------|---------|---------|
| **Idle** | 归零 + 预览边界 | 1. 发送 `$H` 归零命令<br>2. 移动到四个角点<br>3. 激光最小功率（S1）指示边界 | 用户可快速确认工作区域 |
| **Cycle** | 暂停任务 | 设置 `feedHold` 标志位 | 立即暂停运动，激光关闭 |
| **Hold** | 恢复运行 | 设置 `cycleStart` 标志位 | 从暂停位置继续执行 |
| **Alarm** | 尝试归零 | 发送 `$H` 归零命令 | 帮助用户快速解除 Alarm |
| **Jog** | 停止 Jog | 设置 `feedHold` 标志位 | 停止手动移动 |
| **CheckMode** | 查询状态 | 发送 `?` 状态查询 | 显示当前机器状态 |
| **SafetyDoor** | 提示关闭门 | 发送 `?` 状态查询 | 提示用户关闭安全门 |
| **Sleep** | 唤醒查询 | 发送 `?` 状态查询 | 查询睡眠状态 |

##### 长按 3 秒功能（2.8-3.2 秒）

| 机器状态 | 按钮功能 | 执行动作 | 用户体验 |
|---------|---------|---------|---------|
| **Idle** | 启动离线雕刻 | 1. 检查 SD 卡 `/001.nc` 文件<br>2. 发送 `$H` 归零<br>3. 执行 `$SD/Run=/001.nc` | 无需电脑，直接从 SD 卡雕刻 |
| **Cycle** | 停止任务 | 设置 `reset` 标志位（软复位） | 立即停止运动，清除缓冲区 |
| **Hold** | 停止任务 | 设置 `reset` 标志位（软复位） | 取消暂停的任务 |
| **其他状态** | 无操作 | - | 避免误操作 |

##### 超长按 10 秒功能（9.5-10.5 秒）

| 任意状态 | 按钮功能 | 执行动作 | 用户体验 |
|---------|---------|---------|---------|
| **任意** | 重置 WiFi 为 AP 模式 | 1. 发送 `[ESP410]AP` 切换到 AP 模式<br>2. 等待 1 秒<br>3. 发送 `[ESP444]RESTART` 重启 | 用于恢复出厂 WiFi 设置 |

**重要说明**：
- ⚠️ **按钮功能需要 WiFi 就绪**：WiFi 未连接时按钮不响应（防止启动阶段误操作）
- ✅ **状态机设计**：按钮释放后才判断按压时长，避免误触发
- ✅ **10 秒长按立即执行**：达到 10 秒时立即执行，无需等待释放

#### 2.1.2 LED 状态指示（GPIO_NUM_23）

**硬件特性**：
- PWM 控制，25kHz 频率（超声波范围，完全静音）
- 支持共阴极/共阳极 LED（通过 `LED_ACTIVE_HIGH` 配置）
- 刷新率：20ms（50Hz）

**LED 状态优先级**（从高到低）：

| 优先级 | 状态名称 | LED 模式 | 触发条件 | 视觉效果 |
|-------|---------|---------|---------|---------|
| **1** | 警告状态 | 中速闪烁 | `sys.state == State::Alarm` | 0.5s 亮 / 0.2s 灭 |
| **2** | 安全保护触发 | 慢速闪烁 | 安全门打开 OR 倾斜传感器触发 | 0.5s 亮 / 0.5s 灭 |
| **3** | 雕刻状态 | PWM 呼吸灯 | `sys.state == State::Cycle` | 2 秒周期，Gamma 2.5 校正 |
| **4** | WiFi 连接中 | 快速闪烁 | STA 模式未连接 | 0.2s 亮 / 0.2s 灭 |
| **5** | 待机模式 | 常亮 | Idle + WiFi 已连接 | 50% 亮度常亮 |

**LED 模式详解**：

1. **警告状态**（Alarm）
   - 触发场景：限位开关触发、归零失败、G-code 错误
   - 用户操作：短按按钮发送 `$H` 归零，或通过串口发送 `$X` 解锁

2. **安全保护触发**（SafetyDoor）
   - 触发场景：安全门打开或机器倾斜 > 30°
   - 用户操作：关闭安全门或放平机器，系统自动恢复

3. **雕刻状态**（Cycle）
   - 呼吸灯效果：使用 Gamma 2.5 校正，符合人眼感知
   - 亮度变化：0% → 100% → 0%，2 秒完整周期
   - 用户体验：柔和的呼吸效果，指示机器正在工作

4. **WiFi 连接中**（WIFI_CONNECTING）
   - 触发场景：STA 模式下尝试连接 WiFi
   - 持续时间：直到连接成功或超时

5. **待机模式**（STANDBY）
   - 触发场景：机器空闲且 WiFi 已连接
   - 亮度：50%（可通过 `LED_PER_ON` 调整）

**技术细节**：
- **Gamma 校正公式**：`perceived_brightness = linear_brightness ^ 2.5`
- **PWM 分辨率**：根据 `led_output->denominator()` 自动计算
- **极性自适应**：自动根据 `LED_ACTIVE_HIGH` 反转 PWM 占空比

### 2.2 安全保护系统

#### 2.2.1 安全门监控（GPIO_NUM_17）

**硬件特性**：
- 常闭开关（NC - Normally Closed）
- 正常状态：低电平（门关闭）
- 触发状态：高电平（门打开）
- 检测周期：100ms

**触发行为**：

| 机器状态 | 安全门打开时 | 安全门关闭后 | 状态恢复逻辑 |
|---------|-------------|-------------|-------------|
| **Idle** | 进入 SafetyDoor 状态<br>LED 慢速闪烁 | 返回 Idle 状态<br>LED 恢复正常 | 直接恢复 |
| **CheckMode** | 进入 SafetyDoor 状态 | 返回 CheckMode 状态 | 直接恢复 |
| **Homing** | 进入 SafetyDoor 状态<br>归零中断 | 返回 Idle 状态<br>需要重新归零 | 归零失败，需重新执行 |
| **Cycle** | 进入 SafetyDoor 状态<br>立即暂停运动<br>激光关闭 | 进入 Hold 状态<br>等待用户恢复 | **需要按钮恢复**<br>（短按按钮继续） |
| **Hold** | 进入 SafetyDoor 状态<br>保持暂停 | 返回 Hold 状态<br>等待用户恢复 | 保持暂停状态 |
| **Jog** | 进入 SafetyDoor 状态<br>停止 Jog | 进入 Hold 状态 | 需要按钮恢复 |
| **Alarm** | 保持 Alarm 状态 | 保持 Alarm 状态 | 无影响 |
| **SafetyDoor** | 保持 SafetyDoor 状态 | （见上述恢复逻辑） | 根据进入前状态恢复 |
| **Sleep** | 保持 Sleep 状态 | 保持 Sleep 状态 | 无影响 |

**关键特性**：
- ✅ **自定义实现**：不使用 Grbl 标准 Safety Door 功能
- ✅ **智能状态恢复**：根据进入 SafetyDoor 前的状态智能恢复
- ✅ **运动中自动暂停**：Cycle/Jog 状态下门打开立即暂停
- ⚠️ **需要手动恢复**：Cycle/Jog 状态下门关闭后需要短按按钮恢复运行

**状态恢复详解**：

```
进入前状态 → SafetyDoor → 门关闭后状态
─────────────────────────────────────
Idle       → SafetyDoor → Idle        (直接恢复)
Cycle      → SafetyDoor → Hold        (需要按钮恢复)
Hold       → SafetyDoor → Hold        (保持暂停)
Jog        → SafetyDoor → Hold        (需要按钮恢复)
Homing     → SafetyDoor → Idle        (归零失败)
```

#### 2.2.2 倾斜传感器（QMI8658A）

**传感器规格**：
- **型号**: QMI8658A 六轴惯性测量单元（IMU）
- **接口**: I2C，地址 0x6A
- **引脚**: SCL=GPIO_NUM_4, SDA=GPIO_NUM_22
- **功能**: 3 轴加速度计 + 3 轴陀螺仪
- **配置**: ±8g 量程，1000Hz 采样率

**倾斜检测算法**：
1. **采样方式**: 16 次连续采样
2. **数据处理**: 去除最大最小值后计算平均值
3. **归一化**: 将加速度向量归一化到 1000mg
4. **角度计算**: `tilt_angle = atan2(sqrt(X² + Y²), |Z|) × 180 / π`
5. **阈值判断**: 倾斜角度 > 30° 触发保护

**触发行为**：

| 机器状态 | 检测到倾斜时 | 恢复正常后 | 状态恢复逻辑 |
|---------|-------------|-----------|-------------|
| **Idle** | 进入 SafetyDoor 状态<br>LED 慢速闪烁 | 返回 Idle 状态<br>LED 恢复正常 | 直接恢复 |
| **Cycle** | 进入 SafetyDoor 状态<br>立即暂停运动<br>激光关闭 | 进入 Hold 状态<br>等待用户恢复 | **需要按钮恢复** |
| **Hold** | 进入 SafetyDoor 状态<br>保持暂停 | 返回 Hold 状态 | 保持暂停状态 |
| **Alarm** | 保持 Alarm 状态 | 保持 Alarm 状态 | 无影响 |

**自动恢复机制**：
- **连续失败检测**: 如果连续 5 次读取失败（< 4 个有效采样）
- **自动重新初始化**: 重新配置 QMI8658A 寄存器
- **日志输出**: `[TILT] Consecutive failures: 5, attempting re-initialization`

**技术参数**：
- **倾斜阈值**: 30°（可通过代码调整 `TILT_THRESHOLD_DEG`）
- **采样次数**: 16 次（可通过代码调整 `SAMPLE_COUNT`）
- **检测周期**: 100ms
- **精度**: ±5° 误差范围
- **响应时间**: < 200ms（2 个检测周期）

**日志示例**：
```
[I][  1234][TILT] 8.5° (Norm: X=150 Y=-80 Z=980 mg, Samples=16/16)  // 正常
[I][  5678][TILT] 35.2° (Norm: X=520 Y=380 Z=750 mg, Samples=16/16) // 倾斜触发
[I][  5780][TILT] Tilt detected
```

### 2.3 辅助功能

#### 2.3.1 风扇自动控制（GPIO_NUM_16）

**硬件特性**：
- PWM 控制，25kHz 频率（超声波范围，完全静音）
- 占空比范围：0-100%
- 响应时间：< 1s

**控制策略**：

| 时间段 | 控制逻辑 | 风扇状态 | 说明 |
|-------|---------|---------|------|
| **开机后 0-5 分钟** | 固定 50% 占空比 | 持续运行 | 预热冷却系统 |
| **5 分钟后** | 根据激光和运动状态 | 智能控制 | 节能模式 |

**5 分钟后的智能控制逻辑**：

```
风扇开启条件（任一满足）：
├─ 激光主轴开启（spindle->get_state() != SpindleState::Disable）
├─ 机器运动中（sys.state == State::Cycle）
└─ 手动移动中（sys.state == State::Jog）

风扇关闭条件（全部满足）：
├─ 激光主轴关闭
├─ 机器空闲（非 Cycle/Jog 状态）
└─ 距离最后一次活动 > 5 分钟
```

**状态转换示例**：

```
时间轴：
0s    → 开机，风扇 50%
300s  → 5 分钟到，进入智能控制
310s  → 激光开启，风扇保持 50%
320s  → 激光关闭，开始计时
620s  → 5 分钟冷却完成，风扇关闭
630s  → 激光再次开启，风扇立即 50%
```

**日志输出**：
```
[I][    300][FAN ] Fan ON   // 激光开启或运动开始
[I][    620][FAN ] Fan OFF (cooldown complete)  // 冷却完成
```

**技术参数**：
- **冷却时间**: 5 分钟（300 秒）
- **占空比**: 50%（可通过 `FAN_PER_ON` 调整）
- **PWM 频率**: 25kHz
- **检测周期**: 20ms

#### 2.3.2 离线雕刻

**功能说明**：
从 SD 卡读取 G-code 文件并执行，无需连接电脑。

**文件要求**：
- **文件路径**: `/001.nc`（SD 卡根目录）
- **文件格式**: 标准 G-code 文本文件
- **文件名**: 必须为 `001.nc`（区分大小写）
- **SD 卡格式**: FAT32，最大 32GB

**执行流程**：

1. **触发方式**: Idle 状态下长按按钮 3 秒
2. **文件检测**: 检查 SD 卡是否挂载，`/001.nc` 是否存在
3. **自动归零**: 发送 `$H` 归零命令
4. **开始雕刻**: 执行 `$SD/Run=/001.nc`

**错误处理**：

| 错误场景 | 系统行为 | 日志输出 |
|---------|---------|---------|
| SD 卡未插入 | 不执行，输出错误 | `[SD  ] SD card not ready (state=X)` |
| 文件不存在 | 列出根目录文件 | `[SD  ] File 001.nc not found!` |
| 文件格式错误 | G-code 解析器报错 | Grbl 标准错误信息 |

**日志示例**：
```
[I][  1234][OFFL] Wait Homing complete, starting: 001.nc
[I][  1235][SD  ] File 001.nc found (12345 bytes)
```

#### 2.3.3 预览边界

**功能说明**：
使用激光最小功率移动到工作区域四个角点，帮助用户确认雕刻范围。

**触发方式**: Idle 状态下短按按钮

**执行流程**：

1. **自动归零**: 发送 `$H` 归零命令
2. **移动到原点**: `G90G0X0Y0`（绝对坐标，快速移动）
3. **打开激光**: `M4S1`（动态激光模式，功率 S1 = 0.1%）
4. **移动路径**:
   ```
   (0,0) → (100,0) → (100,100) → (0,100) → (0,0)
   左下    右下       右上         左上       返回原点
   ```
5. **关闭激光**: `M5`

**G-code 序列**：
```gcode
$H                    // 归零
G90G0X0Y0             // 移动到原点
M4S1                  // 打开激光，最小功率
G1X100.0Y0F3000       // 移动到右下角
G1X100.0Y100.0        // 移动到右上角
G1X0Y100.0            // 移动到左上角
G1X0Y0                // 返回原点
M5                    // 关闭激光
```

**技术参数**：
- **激光功率**: S1（0.1%，1/1000 最大功率）
- **移动速度**: 3000 mm/min
- **边界尺寸**: 从 `DEFAULT_X_MAX_TRAVEL` / `DEFAULT_Y_MAX_TRAVEL` 读取（100mm × 100mm）
- **激光模式**: M4（动态模式，速度影响功率）

**安全说明**：
- ✅ 激光功率极低（0.1%），仅用于指示，不会造成伤害
- ✅ 移动过程中可随时短按按钮暂停
- ⚠️ 确保工作区域内无障碍物

#### 2.3.4 自动归零

**功能说明**：
WiFi 连接后，如果机器处于 Alarm 状态，自动发送 `$H` 归零命令。

**触发条件**（全部满足）：
1. WiFi 已连接（AP 模式或 STA 模式已连接）
2. 机器状态为 Alarm
3. 安全门关闭
4. 倾斜传感器未触发

**执行流程**：

```
WiFi 连接成功
    ↓
检查机器状态 == Alarm？
    ↓ 是
检查安全门关闭？
    ↓ 是
检查倾斜传感器正常？
    ↓ 是
发送 $H 归零命令
    ↓

```

### 3.2 参数调整建议

#### 倾斜角度阈值调整

**当前值**: 30°
**调整场景**：
- **降低到 15-20°**: 如果机器经常在不平整表面使用，需要更敏感的保护
- **提高到 40-45°**: 如果误触发频繁，且使用环境稳定

**调整方法**：
修改 `wainlux_k11_HIM.cpp` 中的 `TILT_THRESHOLD_DEG` 常量：
```cpp
const float TILT_THRESHOLD_DEG = 30.0f;  // 修改此值
```

**验证方法**：
1. 重新编译并烧录固件
2. 查看串口日志中的倾斜角度值
3. 逐渐倾斜机器，确认触发角度

---

#### 风扇冷却时间调整

**当前值**: 5 分钟
**调整场景**：
- **缩短到 3 分钟**: 如果激光功率较低，散热需求小
- **延长到 10 分钟**: 如果激光功率较高，需要更长冷却时间

**调整方法**：
修改 `wainlux_k11_HIM.cpp` 中的 `COOLDOWN_TIME_MS` 常量：
```cpp
const uint32_t COOLDOWN_TIME_MS = 5 * 60 * 1000;  // 5 分钟
```

**验证方法**：
1. 运行一段雕刻任务
2. 停止后观察风扇关闭时间
3. 查看日志 `[FAN ] Fan OFF (cooldown complete)`

---

#### LED 呼吸灯效果调整

**当前值**: 2 秒周期，Gamma 2.5
**调整场景**：
- **加快周期（1-1.5 秒）**: 更明显的呼吸效果
- **减慢周期（3-5 秒）**: 更柔和的呼吸效果
- **调整 Gamma（2.0-3.0）**: 改变亮度变化曲线

**调整方法**：
修改 `wainlux_k11_HIM.cpp` 中的 `set_led_breath()` 函数：
```cpp
uint32_t cycle_time = 2000;  // 修改周期（毫秒）
float gamma_corrected = pow(linear_brightness, 2.5f);  // 修改 Gamma 值
```

## 五、故障排查指南

### 5.1 按钮无响应

**现象**: 按下按钮无任何反应，LED 无变化，机器无动作

**可能原因**:
1. WiFi 未连接（按钮功能需要 WiFi 就绪）
2. 按钮硬件故障（GPIO_NUM_19 短路或断路）
3. 按钮引脚配置错误

**排查步骤**:
1. **检查 WiFi 连接状态**
   - 观察 LED：常亮或呼吸灯表示 WiFi 已连接
   - 快速闪烁表示 WiFi 连接中，等待连接完成

2. **测试按钮硬件**
   - 使用万用表测试 GPIO_NUM_19 引脚电平
   - 正常状态：高电平（3.3V）
   - 按下状态：低电平（0V）

3. **查看串口日志**
   - 连接串口（115200 波特率）
   - 按下按钮，查看是否有 `[BTN]` 标签的输出
   - 如果无输出，检查按钮任务是否创建成功

**解决方案**:
- WiFi 未连接：等待 WiFi 连接或配置 WiFi
- 硬件故障：更换按钮或检查焊接
- 软件问题：重新烧录固件

---

### 5.2 LED 不亮或闪烁异常

**现象**: LED 完全不亮、常亮不闪烁、或闪烁模式错误

**可能原因**:
1. LED 极性配置错误（共阴极/共阳极）
2. GPIO_NUM_23 与 SD 卡 SPI 冲突
3. LED 硬件故障
4. PWM 频率设置错误

**排查步骤**:
1. **检查 LED 极性配置**
   - 查看代码中的 `LED_ACTIVE_HIGH` 定义
   - 0 = 共阳极（低电平点亮）
   - 1 = 共阴极（高电平点亮）

2. **确认 SD 卡 SPI 引脚配置**
   - 检查 `GRBL_SPI_MOSI` 是否为 GPIO_NUM_13（不是 GPIO_NUM_23）
   - 如果使用默认 VSPI 引脚，会与 LED 冲突

3. **查看串口日志**
   - 查找 `[LED ]` 标签的输出
   - 确认 LED 状态切换：`State changed to: XXX`

4. **测试 PWM 输出**
   - 使用示波器测试 GPIO_NUM_23 的 PWM 输出
   - 频率应为 25kHz

**解决方案**:
- 极性错误：修改 `LED_ACTIVE_HIGH` 配置
- SPI 冲突：确认 SD 卡引脚配置正确
- 硬件故障：更换 LED 或检查焊接
- PWM 错误：检查 `PWM_FREQ_SHARED` 配置

---

### 5.3 倾斜传感器失效

**现象**: 倾斜机器不触发保护，或误触发频繁

**可能原因**:
1. I2C 通信失败（SDA/SCL 引脚错误或接触不良）
2. 传感器未初始化成功
3. 倾斜阈值设置不合理
4. 传感器硬件故障

**排查步骤**:
1. **检查初始化日志**
   - 查找启动日志中的 `[TILT] QMI8658 initialized`
   - 如果初始化失败，会显示错误信息

2. **检查 I2C 引脚连接**
   - SCL = GPIO_NUM_4
   - SDA = GPIO_NUM_22
   - 使用万用表或逻辑分析仪检查 I2C 通信

3. **查看倾斜角度值**
   - 机器水平时，倾斜角度应在 0-10° 范围
   - 查看日志：`[TILT] X.X° (Norm: X=... Y=... Z=... mg, Samples=X/16)`
   - 如果 Z 轴接近 1000mg，表示传感器正常

4. **测试自动恢复机制**
   - 如果连续失败 5 次，系统会自动重新初始化
   - 查看日志：`[TILT] Consecutive failures: 5, attempting re-initialization`

**解决方案**:
- I2C 通信失败：检查引脚连接和上拉电阻
- 阈值不合理：调整 `TILT_THRESHOLD_DEG`（当前 30°）
- 误触发频繁：提高阈值到 40-45°
- 不触发：降低阈值到 15-20°
- 硬件故障：更换 QMI8658A 传感器

---

### 5.4 风扇不转或一直转

**现象**: 风扇完全不转、一直转不停、或转速异常

**可能原因**:
1. PWM 频率设置错误
2. 风扇硬件故障
3. 冷却时间逻辑错误
4. GPIO_NUM_16 引脚故障

**排查步骤**:
1. **查看风扇控制日志**
   - 查找 `[FAN ]` 标签的输出
   - 正常日志：`Fan ON` 和 `Fan OFF (cooldown complete)`

2. **检查 PWM 频率配置**
   - 应为 25kHz（`PWM_FREQ_SHARED`）
   - 使用示波器测试 GPIO_NUM_16 的 PWM 输出

3. **测试风扇硬件**
   - 直接给风扇供电（3.3V 或 5V），确认风扇能转
   - 检查风扇额定电压和电流

4. **验证冷却时间逻辑**
   - 开机后前 5 分钟应持续运行
   - 5 分钟后根据激光和运动状态控制

**解决方案**:
- PWM 频率错误：检查 `PWM_FREQ_SHARED` 配置
- 硬件故障：更换风扇或检查驱动电路
- 逻辑错误：检查 `update_fan_auto_control()` 函数
- 引脚故障：使用万用表测试 GPIO_NUM_16 输出

---

### 5.5 离线雕刻无法启动

**现象**: 长按 3 秒无反应、报错、或文件不执行

**可能原因**:
1. SD 卡未插入或未挂载
2. /001.nc 文件不存在
3. 文件格式错误（非 G-code 文本文件）
4. SD 卡格式不支持（非 FAT32）

**排查步骤**:
1. **检查 SD 卡挂载状态**
   - 查看启动日志中的 SD 卡挂载信息
   - 正常日志：`SD card mounted successfully`

2. **确认文件存在**
   - 使用电脑读取 SD 卡，确认根目录有 `001.nc` 文件
   - 文件名区分大小写，必须为 `001.nc`

3. **查看错误日志**
   - 查找 `[SD  ]` 和 `[OFFL]` 标签的输出
   - 文件不存在：`File 001.nc not found!`
   - SD 卡未就绪：`SD card not ready (state=X)`

4. **验证文件格式**
   - 使用文本编辑器打开 001.nc，确认是 G-code 文本
   - 检查文件编码（应为 ASCII 或 UTF-8）

**解决方案**:
- SD 卡未挂载：重新插入 SD 卡或重启机器
- 文件不存在：创建 001.nc 文件并放入根目录
- 格式错误：重新格式化 SD 卡为 FAT32
- 文件内容错误：检查 G-code 语法

---

### 5.6 自动归零不执行

**现象**: WiFi 连接后仍处于 Alarm 状态，未自动归零

**可能原因**:
1. 安全门打开
2. 倾斜传感器触发
3. 机器状态不是 Alarm
4. 自动归零功能被禁用

**排查步骤**:
1. **检查安全门状态**
   - 确认安全门完全关闭
   - LED 不应处于慢速闪烁状态
   - 查看日志：`[DOOR] Door closed`

2. **检查倾斜传感器**
   - 确认机器放置水平（倾斜角度 < 30°）
   - 查看日志：`[TILT] X.X°`（应 < 30°）

3. **确认机器状态**
   - 查看日志：`sys.state == State::Alarm`
   - 如果状态不是 Alarm，不会触发自动归零

4. **查看自动归零日志**
   - 成功：`[BTN ] Auto-homing triggered (state=Alarm)`
   - 跳过：`[BTN ] Skip auto-homing: XXX`

**解决方案**:
- 安全门打开：关闭安全门
- 倾斜触发：放平机器
- 状态错误：手动触发 Alarm（触发限位开关）
- 功能禁用：检查代码中的自动归零逻辑

## 七、已知限制和注意事项

### 7.1 硬件限制

| 限制项 | 说明 | 影响 |
|-------|------|------|
| 按钮响应延迟 | WiFi 未连接时按钮功能不可用 | 开机后需等待 WiFi 连接（约 5-10 秒） |
| 倾斜传感器精度 | ±5° 误差范围 | 倾斜角度接近阈值时可能不稳定 |
| SD 卡兼容性 | 仅支持 FAT32 格式，最大 32GB | 不支持 exFAT 或 NTFS 格式 |
| 激光预览功率 | 固定 S1（0.1%） | 无法调整预览激光功率 |

### 7.2 使用注意事项

| 注意事项 | 说明 | 建议 |
|---------|------|------|
| 安全门 | 必须完全关闭才能恢复运行 | 确保安全门开关正常工作 |
| 倾斜检测 | 机器必须放置在水平面上（倾斜 < 30°） | 使用水平仪调整机器位置 |
| 离线雕刻 | 文件名必须为 `001.nc`（区分大小写） | 使用小写文件名 |
| WiFi 重置 | 长按 10s 会清除所有 WiFi 配置 | 谨慎使用，避免误操作 |
| 自动归零 | 开机后自动归零可能造成意外移动 | 确保工作区域无障碍物 |

### 7.3 性能参数

| 参数 | 值 | 说明 |
|-----|---|------|
| 按钮防抖 | 50ms | 轮询周期 |
| LED 刷新率 | 20ms（50Hz） | LED 控制任务周期 |
| 倾斜检测周期 | 100ms | 安全监控任务周期 |
| 风扇响应时间 | < 1s | 从检测到执行的延迟 |
| 自动归零延迟 | < 2s | WiFi 连接后到归零开始的延迟 |
