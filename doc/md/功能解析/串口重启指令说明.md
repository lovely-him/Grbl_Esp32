# Grbl_Esp32 串口重启指令说明

## 概述

本文档说明如何通过串口指令重启 Grbl_Esp32 设备。

---

## 主要重启指令

### 指令格式

**基本指令**: `[ESP444]RESTART`

**完整格式**:
```
[ESP444]RESTART pwd=<admin password>
```

### 参数说明

| 参数 | 说明 | 必需 |
|------|------|------|
| `RESTART` | 重启命令关键字（大小写不敏感） | 是 |
| `pwd=<password>` | 管理员密码 | 启用认证时必需 |

### 默认配置

- **默认管理员密码**: `admin`
- **认证开关**: 通过 `#define ENABLE_AUTHENTICATION` 在 [Config.h](../../Grbl_Esp32/src/Config.h) 中配置

---

## 使用示例

### 示例 1: 启用认证时

```
[ESP444]RESTART pwd=admin
```

**响应**:
```
[MSG:Restart ongoing]
```

### 示例 2: 未启用认证时

```
[ESP444]RESTART
```

**响应**:
```
[MSG:Restart ongoing]
```

### 示例 3: 错误的命令

```
[ESP444]REBOOT pwd=admin
```

**响应**:
```
Incorrect command
```

## 实现原理

### 代码位置

#### 1. 命令注册
**文件**: [WebSettings.cpp:1071](../../Grbl_Esp32/src/WebUI/WebSettings.cpp#L1071)

```cpp
new WebCommand("RESTART", WEBCMD, WA, "ESP444", "System/Control", setSystemMode);
```

**说明**:
- `"RESTART"` - 命令参数
- `WEBCMD` - 命令类型
- `WA` - 需要管理员权限 (WebAdmin)
- `"ESP444"` - 命令编号
- `"System/Control"` - 命令分类
- `setSystemMode` - 处理函数

#### 2. 命令处理
**文件**: [WebSettings.cpp:412-419](../../Grbl_Esp32/src/WebUI/WebSettings.cpp#L412-L419)

```cpp
static Error setSystemMode(char* parameter, AuthenticationLevel auth_level) {
    parameter = trim(parameter);
    if (strcasecmp(parameter, "RESTART") != 0) {
        webPrintln("Incorrect command");
        return Error::InvalidValue;
    }
    grbl_send(CLIENT_ALL, "[MSG:Restart ongoing]\r\n");
    COMMANDS::restart_ESP();
    return Error::Ok;
}
```

**处理流程**:
1. 去除参数首尾空格
2. 检查参数是否为 "RESTART"（不区分大小写）
3. 发送重启提示消息到所有客户端
4. 调用重启函数

#### 3. 重启执行
**文件**: [Commands.cpp:76-79](../../Grbl_Esp32/src/WebUI/Commands.cpp#L76-L79)

```cpp
void COMMANDS::handle() {
    COMMANDS::wait(0);
    // 检查是否请求重启
    if (restart_ESP_module) {
        ESP.restart();  // 调用 ESP32 SDK 重启函数
        while (1) {}    // 等待重启完成
    }
}
```

**说明**:
- `ESP.restart()` - ESP32 Arduino 框架提供的重启函数
- `while(1){}` - 防止代码继续执行，等待硬件重启

### 权限级别

## 注意事项

### ⚠️ 重要提醒

1. **数据丢失风险**
   - 重启会导致所有未保存的状态丢失
   - 正在运行的 G-code 程序会中断
   - 建议在空闲状态下重启

2. **认证安全**
   - 默认密码 `admin` 应该在生产环境中修改
   - 密码通过明文传输，建议在安全网络中使用

3. **重启时间**
   - ESP32 重启通常需要 2-3 秒
   - 重启后需要重新建立连接

4. **命令格式**
   - 命令必须用方括号 `[]` 包围
   - 参数大小写不敏感
   - 密码参数格式为 `pwd=<password>`

### 🔧 故障排除

#### 问题 1: 命令无响应
**可能原因**:
- 串口波特率不匹配（默认 115200）
- 命令格式错误
- 设备已死机

**解决方法**:
- 检查串口配置
- 确认命令格式正确
- 尝试硬件复位（按复位按钮）

#### 问题 2: 认证失败
**可能原因**:
- 密码错误
- 未启用认证但提供了密码
- 密码包含特殊字符

**解决方法**:
- 确认密码正确
- 检查 `ENABLE_AUTHENTICATION` 配置
- 使用简单密码测试

#### 问题 3: 重启后无法连接
**可能原因**:
- WiFi 配置丢失
- IP 地址变化（DHCP）
- 蓝牙未自动启动

**解决方法**:
- 使用串口连接检查状态
- 使用 `[ESP111]` 查询新 IP
- 检查 WiFi/BT 配置

## 示例代码

### Python 串口重启示例

```python
import serial
import time

# 配置串口
ser = serial.Serial(
    port='COM3',           # 根据实际情况修改
    baudrate=115200,
    timeout=1
)

# 发送重启命令
command = "[ESP444]RESTART pwd=admin\n"
ser.write(command.encode())

# 读取响应
time.sleep(0.1)
response = ser.read_all().decode()
print(f"响应: {response}")

# 关闭串口
ser.close()

print("设备正在重启...")
```

### Arduino 串口重启示例

```cpp
void restartGrbl() {
    // 发送重启命令
    Serial.println("[ESP444]RESTART pwd=admin");

    // 等待响应
    delay(100);

    // 读取响应
    while (Serial.available()) {
        String response = Serial.readStringUntil('\n');
        Serial.print("响应: ");
        Serial.println(response);
    }
}
```

### JavaScript (Node.js) 串口重启示例

```javascript
const SerialPort = require('serialport');
const Readline = require('@serialport/parser-readline');

// 打开串口
const port = new SerialPort('COM3', {
    baudRate: 115200
});

const parser = port.pipe(new Readline({ delimiter: '\n' }));

// 监听响应
parser.on('data', (data) => {
    console.log('响应:', data);
});

// 发送重启命令
port.write('[ESP444]RESTART pwd=admin\n', (err) => {
    if (err) {
        console.error('发送失败:', err.message);
    } else {
        console.log('重启命令已发送');
    }
});
```
