# Grbl_Esp32 风扇/冷却液控制完全指南

## 概述

Grbl_Esp32 通过 **Coolant Control（冷却液控制）** 功能来控制风扇或冷却液泵。虽然名称是"冷却液"，但在实际应用中，这些输出引脚常用于控制：

- **风扇** - 主轴冷却风扇、电子设备散热风扇
- **冷却液泵** - CNC 铣床的切削液泵
- **气泵** - 压缩空气吹屑系统
- **其他辅助设备** - 吸尘器、照明灯等

---

## G-code 命令

### 基本命令

| 命令 | 功能 | 说明 |
|------|------|------|
| `M7` | 开启 Mist（雾化冷却液） | 控制 `COOLANT_MIST_PIN` 引脚 |
| `M8` | 开启 Flood（喷淋冷却液） | 控制 `COOLANT_FLOOD_PIN` 引脚 |
| `M9` | 关闭所有冷却液 | 同时关闭 M7 和 M8 |

### 使用示例

#### 示例 1: 控制单个风扇

```gcode
M7          ; 开启风扇（Mist 引脚）
G0 X10 Y10  ; 移动到位置
M9          ; 关闭风扇
```

#### 示例 2: 同时使用两个输出

```gcode
M7          ; 开启风扇 1（Mist 引脚）
M8          ; 开启风扇 2（Flood 引脚）
G1 X50 F100 ; 执行加工
M9          ; 同时关闭两个风扇
```

#### 示例 3: 在程序中自动控制

```gcode
G21         ; 单位：毫米
G90         ; 绝对坐标
M3 S1000    ; 启动主轴，转速 1000 RPM
M7          ; 开启冷却风扇
G0 Z5       ; 快速移动到安全高度
G0 X0 Y0    ; 移动到起始位置
G1 Z-2 F50  ; 下刀
G1 X50 F200 ; 切削
G0 Z5       ; 抬刀
M5          ; 停止主轴
M9          ; 关闭风扇
M30         ; 程序结束
```

## 硬件配置

### 1. 在机器配置文件中定义引脚

在你的机器配置文件（如 `Machines/My_Machine.h`）中定义冷却液引脚：

```cpp
// 定义冷却液/风扇控制引脚
#define COOLANT_MIST_PIN   GPIO_NUM_21  // M7 控制的引脚
#define COOLANT_FLOOD_PIN  GPIO_NUM_25  // M8 控制的引脚
```

### 2. 引脚反转（可选）

如果你的继电器或驱动电路是低电平触发，可以反转引脚逻辑：

```cpp
#define COOLANT_MIST_PIN   GPIO_NUM_21
#define INVERT_COOLANT_MIST_PIN  // 反转 Mist 引脚逻辑

#define COOLANT_FLOOD_PIN  GPIO_NUM_25
#define INVERT_COOLANT_FLOOD_PIN // 反转 Flood 引脚逻辑
```

**反转效果**:
- 未反转: M7 → 引脚输出 HIGH (3.3V)
- 已反转: M7 → 引脚输出 LOW (0V)

### 3. 只使用一个输出

如果只需要一个风扇控制，只定义一个引脚即可：

```cpp
// 只定义 Mist 引脚，使用 M7/M9 控制
#define COOLANT_MIST_PIN   GPIO_NUM_21

// COOLANT_FLOOD_PIN 不定义，M8 命令将被忽略
```

## 硬件连接

### 方案 1: 直接驱动小型风扇（不推荐）

**警告**: ESP32 GPIO 最大输出电流仅 **12mA**，不能直接驱动大功率设备！

```
ESP32 GPIO 21 ──┬── 风扇正极 (3.3V, <10mA)
                │
               GND ── 风扇负极
```

**适用场景**: 仅适用于极小功率的信号风扇（<30mW）

### 方案 2: 使用 MOSFET 驱动（推荐）

适用于 12V/24V 风扇、继电器等中等功率设备。

```
                    +12V/24V
                      │
                      ├─── 风扇正极
                      │
ESP32 GPIO 21 ───┬───┤ MOSFET (IRLZ44N)
                 │    │   Gate
                 │    │
                10K   └─── 风扇负极
                 │         │
                GND ───────┴─── GND
```

**推荐 MOSFET**: IRLZ44N, IRL540N (逻辑电平 MOSFET)

**元件清单**:
- MOSFET: IRLZ44N (Vgs(th) < 2V)
- 下拉电阻: 10kΩ (防止 GPIO 悬空时误触发)
- 续流二极管: 1N4007 (如果驱动感性负载如风扇)

### 方案 3: 使用继电器模块（最简单）

适用于大功率设备（>100W）或交流电设备。

```
ESP32 GPIO 21 ──→ 继电器模块 IN
ESP32 GND     ──→ 继电器模块 GND
ESP32 3.3V    ──→ 继电器模块 VCC (如果需要)

继电器输出:
  COM ──→ 电源正极 (12V/24V/220V)
  NO  ──→ 风扇/设备正极
  设备负极 ──→ 电源负极
```

**推荐模块**: 5V 低电平触发继电器模块（带光耦隔离）

**注意事项**:
- 使用 `INVERT_COOLANT_MIST_PIN` 如果模块是低电平触发
- 确保继电器额定电流大于负载电流的 1.5 倍
- 交流电设备必须使用继电器，不能用 MOSFET

### 方案 4: 使用固态继电器（SSR）

适用于需要频繁开关的大功率设备。

```
ESP32 GPIO 21 ──→ SSR 输入正极 (+)
ESP32 GND     ──→ SSR 输入负极 (-)

SSR 输出:
  负载正极 ──→ 电源正极
  负载负极 ──→ 电源负极
```

**优点**: 无机械触点、寿命长、无噪音、开关速度快

**文件**: `Machines/My_Machine_Inverted.h`


- M7 → GPIO 21 输出 LOW (0V) → 继电器闭合 → 风扇开启

## 实时控制（覆盖功能）

除了 G-code 命令，Grbl 还支持通过实时命令控制冷却液：

### 实时命令

| 命令 | 功能 | 说明 |
|------|------|------|
| `Ctrl-A` | 切换 Flood 状态 | 立即开/关 Flood |
| `Ctrl-B` | 切换 Mist 状态 | 立即开/关 Mist |

**特点**:
- 不需要等待缓冲区清空
- 可以在程序运行中随时切换
- 不会影响 G-code 程序的状态

### 通过串口发送实时命令

```python
import serial

ser = serial.Serial('COM3', 115200)

# 切换 Flood 状态（Ctrl-A = 0x01）
ser.write(b'\x01')

# 切换 Mist 状态（Ctrl-B = 0x02）
ser.write(b'\x02')
```

## 状态查询

### 查询当前冷却液状态

发送 `?` 命令查询实时状态：

```
?
<Idle|MPos:0.000,0.000,0.000|FS:0,0|Ov:100,100,100|A:SFM>
```

**状态标志**:
- `A:` - 附加状态标志
  - `S` - 主轴开启
  - `F` - Flood 开启
  - `M` - Mist 开启

**示例**:
- `A:S` - 仅主轴开启
- `A:SF` - 主轴和 Flood 开启
- `A:SFM` - 主轴、Flood、Mist 全部开启
- `A:` - 全部关闭

## 代码实现分析

### 1. 命令解析

**文件**: [GCode.cpp:500-519](../../Grbl_Esp32/src/GCode.cpp#L500-L519)

```cpp
case 7:
case 8:
case 9:
    switch (int_value) {
#ifdef COOLANT_MIST_PIN
        case 7:
            gc_block.coolant = GCodeCoolant::M7;
            break;
#endif
#ifdef COOLANT_FLOOD_PIN
        case 8:
            gc_block.coolant = GCodeCoolant::M8;
            break;
#endif
        case 9:
            gc_block.coolant = GCodeCoolant::M9;
            break;
    }
    mg_word_bit = ModalGroup::MM8;
    break;
```

**说明**:
- 如果未定义 `COOLANT_MIST_PIN`，M7 命令会被忽略
- 如果未定义 `COOLANT_FLOOD_PIN`，M8 命令会被忽略
- M9 始终可用，用于关闭所有冷却液

### 2. 状态执行

**文件**: [GCode.cpp:1381-1396](../../Grbl_Esp32/src/GCode.cpp#L1381-L1396)

```cpp
switch (gc_block.coolant) {
    case GCodeCoolant::None:
        break;
    case GCodeCoolant::M7:
        gc_state.modal.coolant.Mist = 1;
        coolant_sync(gc_state.modal.coolant);
        break;
    case GCodeCoolant::M8:
        gc_state.modal.coolant.Flood = 1;
        coolant_sync(gc_state.modal.coolant);
        break;
    case GCodeCoolant::M9:
        gc_state.modal.coolant = {};  // 清零所有标志
        coolant_sync(gc_state.modal.coolant);
        break;
}
```

**关键点**:
- M7 和 M8 是**累加**的，可以同时开启
- M9 会**同时关闭** Mist 和 Flood
- `coolant_sync()` 确保在运动缓冲区同步后才执行

### 3. 硬件控制

**文件**: [CoolantControl.cpp:77-95](../../Grbl_Esp32/src/CoolantControl.cpp#L77-L95)

```cpp
static inline void coolant_write(CoolantState state) {
    bool pinState;

#ifdef COOLANT_FLOOD_PIN
    pinState = state.Flood;
#ifdef INVERT_COOLANT_FLOOD_PIN
    pinState = !pinState;
#endif
    digitalWrite(COOLANT_FLOOD_PIN, pinState);
#endif

#ifdef COOLANT_MIST_PIN
    pinState = state.Mist;
#ifdef INVERT_COOLANT_MIST_PIN
    pinState = !pinState;
#endif
    digitalWrite(COOLANT_MIST_PIN, pinState);
#endif
}
```

**说明**:
- 直接使用 `digitalWrite()` 控制 GPIO
- 支持引脚反转逻辑
- 如果引脚未定义，相应代码不会编译

## 高级应用

### 1. 自动风扇控制（通过 M30 回调）

在机器配置文件中实现自动关闭风扇：

```cpp
// 在机器配置文件中定义
void user_m30() {
    // 程序结束时自动关闭所有风扇
    coolant_off();

    // 也可以关闭主轴
    spindle->stop();

    // 发送通知
    grbl_msg_sendf(CLIENT_SERIAL, MsgLevel::Info, "Program complete, all outputs off");
}
```

### 2. 温度控制风扇（需要额外硬件）

如果有温度传感器，可以在 `machine_init()` 中启动温度监控任务：

```cpp
void machine_init() {
    // 创建温度监控任务
    xTaskCreate(
        temperature_monitor_task,  // 任务函数
        "TempMonitor",             // 任务名称
        2048,                      // 栈大小
        NULL,                      // 参数
        1,                         // 优先级
        NULL                       // 任务句柄
    );
}

void temperature_monitor_task(void* parameter) {
    while (true) {
        float temp = read_temperature();  // 读取温度

        if (temp > 50.0) {
            // 温度过高，强制开启风扇
            CoolantState state = {};
            state.Mist = 1;
            coolant_set_state(state);
        } else if (temp < 40.0) {
            // 温度正常，可以关闭风扇
            coolant_off();
        }

        vTaskDelay(pdMS_TO_TICKS(5000));  // 每 5 秒检查一次
    }
}
```

### 3. PWM 调速风扇（需要修改代码）

默认的冷却液控制是开/关，如果需要 PWM 调速：

```cpp
// 在机器配置文件中定义
#define FAN_PWM_PIN     GPIO_NUM_21
#define FAN_PWM_CHANNEL 0
#define FAN_PWM_FREQ    25000  // 25kHz

void machine_init() {
    // 配置 PWM
    ledcSetup(FAN_PWM_CHANNEL, FAN_PWM_FREQ, 8);  // 8 位分辨率
    ledcAttachPin(FAN_PWM_PIN, FAN_PWM_CHANNEL);
    ledcWrite(FAN_PWM_CHANNEL, 0);  // 初始关闭
}

// 自定义函数设置风扇速度
void set_fan_speed(uint8_t speed) {
    // speed: 0-100 (百分比)
    uint8_t duty = map(speed, 0, 100, 0, 255);
    ledcWrite(FAN_PWM_CHANNEL, duty);
}
```

**注意**: 这需要修改核心代码或使用自定义 M 代码。

## 常见问题

### 1. M7/M8 命令无响应

**可能原因**:
- 机器配置文件中未定义 `COOLANT_MIST_PIN` 或 `COOLANT_FLOOD_PIN`
- 引脚定义错误
- 硬件连接问题

**排查步骤**:
```bash
# 1. 检查启动日志
# 应该看到类似信息:
[MSG:Mist coolant on pin GPIO(21)]
[MSG:Flood coolant on pin GPIO(25)]

# 2. 如果没有看到，说明引脚未定义
# 检查 Machine.h 和机器配置文件

# 3. 测试引脚输出
M7          # 开启 Mist
?           # 查询状态，应该看到 A:M
M9          # 关闭
?           # 查询状态，A: 应该为空
```

### 2. 风扇不转但命令有响应

**可能原因**:
- GPIO 输出电流不足（ESP32 最大 12mA）
- 需要驱动电路（MOSFET 或继电器）
- 风扇电压不匹配

**解决方法**:
- 使用 MOSFET 或继电器驱动
- 检查风扇额定电压（12V/24V）
- 使用万用表测量 GPIO 输出电压

### 3. 引脚反转不生效

**可能原因**:
- 宏定义位置错误
- 拼写错误

**正确定义**:
```cpp
#define COOLANT_MIST_PIN         GPIO_NUM_21
#define INVERT_COOLANT_MIST_PIN  // 必须在同一文件中定义
```

**错误示例**:
```cpp
// 错误：在不同文件中定义
// Machine.h:
#define COOLANT_MIST_PIN GPIO_NUM_21

// Config.h:
#define INVERT_COOLANT_MIST_PIN  // 不会生效！
```

### 4. M9 无法关闭风扇

**可能原因**:
- 硬件锁存（继电器自锁）
- 引脚反转配置错误
- 代码被修改

**排查**:
```bash
# 1. 测试引脚状态
M7          # 开启
# 用万用表测量引脚电压

M9          # 关闭
# 再次测量引脚电压，应该变化

# 2. 如果电压变化但风扇不停，是硬件问题
# 3. 如果电压不变化，是软件问题
```

### 5. 风扇在启动时自动开启

**可能原因**:
- GPIO 上电默认状态
- 引脚反转配置错误
- 继电器是常闭型

**解决方法**:
```cpp
// 方法 1: 使用下拉电阻（硬件）
// 在 GPIO 和 GND 之间连接 10kΩ 电阻

// 方法 2: 在 machine_init() 中强制关闭
void machine_init() {
    coolant_off();  // 确保启动时风扇关闭
}

// 方法 3: 检查引脚反转配置
// 如果继电器是低电平触发，必须定义反转
#define INVERT_COOLANT_MIST_PIN
```

## 最佳实践

### 1. 引脚选择

**推荐使用的 GPIO**:
- GPIO 4, 13, 14, 16, 17, 21, 22, 23, 25, 26, 27, 32, 33

**避免使用的 GPIO**:
- GPIO 0: 启动模式选择（下拉进入下载模式）
- GPIO 2: 必须悬空或下拉才能从 Flash 启动
- GPIO 5: VSPI CS0，启动时必须为高电平
- GPIO 12: MTDI，启动时电平影响 Flash 电压
- GPIO 15: MTDO，启动时必须为高电平
- GPIO 34-39: 仅输入，不能用于输出

### 2. 安全考虑

```cpp
// 在机器配置文件中实现安全功能
void user_m30() {
    // 程序结束时自动关闭所有输出
    coolant_off();
    spindle->stop();
}

// 紧急停止时也关闭风扇
// 这已经在 Grbl 核心代码中实现
// 参见 System.cpp 中的 mc_reset()
```

### 3. 文档化配置

在机器配置文件中添加注释：

```cpp
// 冷却液/风扇配置
#define COOLANT_MIST_PIN   GPIO_NUM_21  // 主轴冷却风扇 (12V, 0.5A)
                                        // 通过 MOSFET IRLZ44N 驱动
                                        // M7 开启, M9 关闭

#define COOLANT_FLOOD_PIN  GPIO_NUM_25  // 切削液泵 (24V, 2A)
                                        // 通过 5V 继电器模块驱动

```

## 总结

### 快速参考

| 需求 | 命令 | 配置 |
|------|------|------|
| 单个风扇 | M7/M9 | `#define COOLANT_MIST_PIN GPIO_NUM_21` |
| 两个风扇 | M7/M8/M9 | 定义 MIST 和 FLOOD 引脚 |
| 低电平触发 | M7/M9 | 添加 `INVERT_COOLANT_MIST_PIN` |
| 查询状态 | `?` | 查看 `A:` 标志 |
| 实时控制 | Ctrl-A/B | 无需配置 |

### 关键要点

1. ✅ M7 控制 `COOLANT_MIST_PIN`，M8 控制 `COOLANT_FLOOD_PIN`
2. ✅ M9 同时关闭两个输出
3. ✅ M7 和 M8 可以同时开启
4. ✅ ESP32 GPIO 输出电流有限（12mA），需要驱动电路
5. ✅ 使用 `INVERT_` 宏适配低电平触发继电器
6. ✅ 避免使用启动敏感引脚（GPIO 0, 2, 5, 12, 15）
